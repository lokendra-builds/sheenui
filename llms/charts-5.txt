## Scatter Plot & Bubble Chart for React

URL: https://lokendra-builds.github.io/sheenui/charts/scatter-plot
Sidebar name: Scatter & bubble chart

A React scatter plot and bubble chart with nearest-point hover, arrow-key navigation and a least-squares trend line in one prop. Animated, accessible, MIT.

What it is: A React scatter plot and bubble chart that shows how two measures relate, one dot per item, with an optional trend line. Pass series as readonly ScatterSeries[]: each a label plus a data array of { x, y } points, with an optional size for bubbles.

### Example 1 of 3: Scatter with trend lines

Two series, each with its own fitted trend (dotted, so it never reads as data). Their slope and R² are part of the chart's accessible name.

```tsx
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
import { formatCompact } from "@/components/sheenui/charts/chart-utils";
import { scatterLegend, ScatterTable, ScatterChart, type ScatterSeries } from "@/components/sheenui/charts/scatter-chart";
// Package build (after the first npm release, or a packed tarball): import { ChartCard, formatCompact, scatterLegend, ScatterTable, ScatterChart, type ScatterSeries } from "@sheenui/theme";

const usd = (n: number) => "$" + formatCompact(n);

const series: ScatterSeries[] = [
  {
    label: "Search",
    color: 1,
    data: [
      { x: 2400, y: 11800, label: "Week 1" },
      { x: 3600, y: 15200, label: "Week 2" },
      { x: 4800, y: 18900, label: "Week 3" },
      { x: 6100, y: 22100, label: "Week 4" },
    ],
  },
  {
    label: "Social",
    color: 2,
    data: [
      { x: 2100, y: 12800, label: "Week 1" },
      { x: 3300, y: 14600, label: "Week 2" },
      { x: 4500, y: 17900, label: "Week 3" },
      { x: 5900, y: 19400, label: "Week 4" },
    ],
  },
];

export function Example() {
  return (
    <ChartCard
      title="Ad spend vs revenue"
      legend={scatterLegend(series)}
      table={<ScatterTable series={series} xLabel="Spend" yLabel="Revenue" formatX={usd} formatY={usd} />}
    >
      <ScatterChart
        trendline
        series={series}
        xLabel="Weekly spend"
        yLabel="Weekly revenue"
        formatX={usd}
        formatY={usd}
        aria-label="Weekly ad spend against revenue, by channel"
      />
    </ChartCard>
  );
}
```

A single point gets a padded axis around it; a fourth series folds into a neutral “Other” (in a scatter every color is compared with every other, so three is the limit).

### Accessibility

- The chart is one focusable figure: its aria-label is the chart title, a one-line hint describes how to read it, and in a ChartCard with a table view aria-details points at that table. Each move is announced politely, once. Each move announces the point's x, y (and size, for bubbles).
- ScatterTable is the same data as a real table. Pass it to ChartCard's table prop and the Chart / Table tabs let anyone read every value without color or sight.
- With reduced motion on, the points start at their final positions and a data change jumps straight to the new state.

### All exports on this page

- MAX_SCATTER_SERIES — In a scatter every colour is compared with every other ("all pairs"): three is the safe limit.
- ScatterChart — A scatter plot of x against y, with optional bubble sizes and trendline.
- ScatterTable — The table view of a scatter chart: one row per point, grouped by series (with the same "Other" fold).
- defaultScatterChartLabels — The built-in English strings of ScatterChart; spread it into your own labels and change what you need.
- foldScatterSeries — The series as drawn: the first three keep their colour slot, the rest fold into a neutral "Other".
- linearRegression — Least-squares fit y = slope * x + intercept, with R².
- scatterLegend — Legend items for a scatter chart, with the same "Other" fold as the chart.


### When to use the scatter plot and bubble chart

- Use it as a scatter chart with a trend line for ad spend against revenue per week, where you want to see whether two measures move together and quantify the relationship with a fitted line.
- It suits a bubble chart of cities, plotting rent against salary with bubble area showing population so a small number of large points stays visible.
- It works for comparing up to three groups, such as two campaigns, each with its own series color and its own trend line with slope and R squared.
- Skip it when one axis is categorical or time, where LineChart or BarChart fit better; for thousands of points of one variable, Beeswarm or Histogram shows the distribution more clearly.
- Pair it with ChartCard for the title, legend and Chart / Table tabs, ScatterTable for the text twin, and scatterLegend so a folded Other series is labeled the same way.


### Frequently asked questions

#### How do I add a trend line to a scatter plot in React?

Set trendline on ScatterChart. It fits a least-squares line per series, drawn dotted and clipped to the plot so it never reads as data. The slope and R squared are part of the chart's accessible name. linearRegression is exported too.

#### How do I turn it into a bubble chart?

Set bubble and give each point a size. Bubbles are sized by area, so four times the population is four times the ink, with a minimum of 8px across. Big bubbles sit behind small ones, each with a surface ring.

#### How many series can I plot?

Up to three; series past the third fold into one neutral Other series, because in a scatter every color sits beside every other. Each series is a label, optional color and a data array of x, y, optional size, label and id.

#### How do the keyboard and pointer find points?

The pointer only has to be near a point, since hit testing finds the nearest one. With the keyboard, Left and Right move through points in x order, Up and Down in y order, Home and End to the first and last in x order, and Escape clears the reading.

## Sparkbar: Mini Bar Chart for React Tables

URL: https://lokendra-builds.github.io/sheenui/charts/sparkbar
Sidebar name: Sparkbar

### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| values | readonly (number \| null \| undefined)[] | required | Values, oldest first. A missing (non-numeric) entry leaves its slot empty: a gap, never a zero. |
| variant | "bar" \| "winloss" | "bar" | "bar": tiny columns, sized by value (negative values hang below a zero line). "winloss": only the sign counts: up for a win (> 0), down for a loss (< 0), a dash for a draw (0). |
| highlight | number \| "none" \| "last" | variant === "bar" ? "last" : "none" | Which bar to emphasise at full strength; the rest step back to a lighter step of the same hue. "last" (the latest value; default for "bar"), "none" (default for "winloss"), or an index into values (negative counts from the end: -1 is the last entry). An index outside values, or on a gap, emphasises nothing. |
| color | ChartColor | 1 | Colour slot of the bars ("bar"), or of wins ("winloss"). |
| negativeColor | ChartColor | 2 | Sets the colour slot of losses ("winloss"). |
| height | number | 32 | Height of the chart in px; the width follows the container. |
| format | ((n: number) => string) | formatCompact | Formats the low / high / latest values in the spoken summary. |
| aria-label | string | optional, no default | Name the trend, e.g. "Weekly signups". A summary of the values is appended. Without it the sparkbar is decorative. |

### Example 2 of 2: Win / loss in a table

Only the sign counts: up for a win, down for a loss, a short dash for a draw. Wins and losses use two distinct palette hues (not success and danger: a loss isn't an error).

```tsx
import { Sparkbar } from "@/components/sheenui/charts/sparkbar";
import { GlassCard } from "@/components/sheenui/glass-card/glass-card";
// Package build (after the first npm release, or a packed tarball): import { GlassCard, Sparkbar } from "@sheenui/theme";

const standings = [
  { team: "Harbour City", results: [1, 1, -1, 1, 1, 0, 1, 1, -1, 1, 1, 1] },
  { team: "Northfield Rovers", results: [1, -1, 1, 0, 1, -1, 1, 1, 0, -1, 1, 1] },
  { team: "Ashdown Athletic", results: [-1, 1, 0, -1, 1, -1, -1, 1, 1, 0, -1, 1] },
  { team: "Kestrel Town", results: [-1, -1, 1, -1, 0, -1, 1, -1, -1, 1, -1, 0] },
];

export function Example() {
  return (
    <GlassCard className="overflow-hidden p-0">
      <div role="region" aria-label="League form" tabIndex={0} className="overflow-x-auto">
        <table className="w-full min-w-[30rem] text-start text-sm">
          <caption className="sr-only">League form, last 12 matches</caption>
          <thead className="text-xs text-sheen-fg-muted">
            <tr className="border-b border-sheen-border">
              <th scope="col" className="px-5 py-3 font-medium">Team</th>
              <th scope="col" className="px-5 py-3 font-medium">Last 12</th>
              <th scope="col" className="px-5 py-3 text-end font-medium">W–D–L</th>
            </tr>
          </thead>
          <tbody>
            {standings.map((row) => {
              const w = row.results.filter((r) => r > 0).length;
              const l = row.results.filter((r) => r < 0).length;
              return (
                <tr key={row.team} className="border-b border-sheen-border last:border-0">
                  <th scope="row" className="px-5 py-3 font-medium whitespace-nowrap">{row.team}</th>
                  <td className="w-56 px-5 py-3">
                    <Sparkbar
                      variant="winloss"
                      height={24}
                      values={row.results}
                      aria-label={`${row.team}, last 12 matches`}
                    />
                  </td>
                  <td className="px-5 py-3 text-end whitespace-nowrap tabular-nums">
                    {w}–{row.results.length - w - l}–{l}
                  </td>
                </tr>
              );
            })}
          </tbody>
        </table>
      </div>
    </GlassCard>
  );
}
```

### When to use the sparkbar chart

- Use it as a sparkline bar chart inside a stat tile to show the last twelve periods of a metric beside the current number, with the latest bar at full strength and history in a lighter tint.
- It fits a table cell showing a team's recent record, using variant winloss so only the sign of each result is drawn: up for a win, down for a loss, a short dash for a draw.
- It works for tiny trend hints in a list of accounts or projects, where hundreds of rows need a glanceable shape and not a full chart with axes.
- Skip it when readers need to hover for values or compare axes, since a sparkbar is not interactive; use BarChart for that, or Sparkline when the series is a continuous line rather than discrete periods.
- Pair it with Sparkline for continuous trends, Badge or a plain number for the headline value next to it, and DataTable to place a sparkbar in a column.


### Frequently asked questions

#### How is a mini bar chart in React different from a sparkline?

Sparkbar is the bar twin of Sparkline: each value is a discrete period drawn as its own bar, sized by value, with negative values hanging from a zero line. Use it for counts per day, week or month.

#### How do I highlight a specific bar?

highlight defaults to last in bar mode and none in win/loss mode. Pass a number to index values, with negatives counting from the end, or none when no period is special. The other bars step back to a lighter tint of the same hue.

#### What does a screen reader hear?

With an aria-label, the sparkbar is an image named by that label plus a summary: low, high and latest, or the win/loss record, or No data. Without a label it is decorative, so put the number it summarizes beside it as text.

#### How are missing values handled?

values accepts numbers, null or undefined, oldest first. A missing entry leaves its slot empty, so there is a gap and never a zero. Bars never grow wider than 12px, height defaults to 32, and the width follows the container.

Focus the chart, then Left and Right (or Up and Down) move to the previous or next point, and Home and End jump to the ends. The hover band and crosshair snap to the step under the pointer, and the tooltip lists each series' value there.

### Accessibility

- The chart is one focusable figure; each step through time announces every layer's value and share, largest first, then the total. With a layer picked, only that layer is read.
- Layer names sit on solid tags of the chart surface, so they meet AA contrast on any layer color; layers that are too thin for a name rely on the legend and the tooltip.
- Color slots are fixed per series and never repeat: more than 8 layers fold into a gray “Other”.

- The table view lists every value with a total column. Reduced motion draws the layers in place.

### When to use Streamgraph

- Use it as a stream chart for a year of listening hours by genre, where the shape of each layer shows how a mix swells and fades across 52 weeks.
- It suits traffic sources around a launch, with thirty days of visits by source and a spike in week three, where the stream's thickness is always the total.
- It works for any many-category time series where totals matter less than the rhythm of change, with layer names printed inside their thickest stretch when they fit.
- Skip it when readers must read exact values or compare layers against a common baseline; StackedAreaChart keeps a flat bottom, and LineChart compares individual series better.
- Pair it with ChartCard and its legend, StreamgraphTable for exact values as text, and a SegmentedControl to switch offset between wiggle and silhouette.


### Frequently asked questions

#### What is the difference between wiggle and silhouette?

offset defaults to wiggle, Byron and Wattenberg's minimal-wiggle baseline, which keeps layers as flat as they can be. Silhouette mirrors the stream around a center line. In both, the total is the stream's thickness.

#### How are layers ordered?

order defaults to insideOut, which puts layers that peak mid-way in the middle. Set none to keep your series order from bottom up. Each series has a fixed color slot, and series past eight fold into Other.

#### How do I read a layer with the keyboard?

Left and Right move through time, Up and Down pick a layer top to bottom as stacked on screen, Home and End jump to the first or last point, and Escape clears the layer. Hovering a layer lights it and dims the rest, and the crosshair reads every layer with its share.

#### Can I hide the inline layer names?

Set inlineLabels to false. By default each layer is named inside its thickest stretch, only when the name fits. The legend, tooltip and StreamgraphTable always carry every name, and height defaults to 300px.

### Example 1 of 2: Two series, one sample a second

useStreamingData calls your function every second and keeps a rolling buffer; the chart and its table both read it. Call it in the small component that renders the card, so each sample re-renders only that card. Hover, tap or arrow through the line to hold the view and read values. Pause stops the view; data keeps arriving and Resume glides to the present.

```tsx
import { useEffect, useRef, useState } from "react";
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
import { type ChartSeries } from "@/components/sheenui/charts/chart-utils";
import { StreamingChart } from "@/components/sheenui/charts/streaming-chart";
import { useStreamingData } from "@/components/sheenui/charts/streaming-chart/model";
import { StreamingTable } from "@/components/sheenui/charts/streaming-chart/parts";
// Package build (after the first npm release, or a packed tarball): import { useStreamingData, ChartCard, StreamingTable, StreamingChart, type ChartSeries } from "@sheenui/theme";

const series: ChartSeries[] = [
  { key: "cpu", label: "CPU", color: 1 },
  { key: "memory", label: "Memory", color: 3 },
];
const percent = (n: number) => Math.round(n) + "%";

// Stand-ins for your metrics source: replace them with a real reading.
const readCpu = () => 35 + Math.random() * 30;
const readMemory = () => 55 + Math.random() * 10;

// The hook lives in the card's own component: a sample re-renders this card, not the page.
// Off-screen the feed rests (idle) and the missed samples are filled in when it's back.
export function Example() {
  const ref = useRef<HTMLDivElement>(null);
  const [near, setNear] = useState(true);
  useEffect(() => {
    const el = ref.current;
    if (!el) return;
    const observer = new IntersectionObserver(([entry]) => setNear(entry?.isIntersecting ?? true), { rootMargin: "200px" });
    observer.observe(el);
    return () => observer.disconnect();
  }, []);
  const data = useStreamingData(
    () => ({ cpu: readCpu(), memory: readMemory() }),
    { rate: 1000, history: 60, idle: !near },
  );
  return (
    <div ref={ref}>
      <ChartCard title="web-01" table={<StreamingTable data={data} series={series} format={percent} />}>
        <StreamingChart
          data={data}
          series={series}
          rate={1000}
          window={60}
          format={percent}
          aria-label="CPU and memory of web-01, last minute"
        />
      </ChartCard>
    </div>
  );
}
```

### Example 2 of 2: Fast feed with a zero baseline

Two samples a second, 40 seconds in view, the axis anchored at zero. Push your own rows (from a socket, say) and the chart animates them the same way.

```tsx
import { useEffect, useState } from "react";
import { type ChartRow } from "@/components/sheenui/charts/chart-utils";

// Package build (after the first npm release, or a packed tarball): import { StreamingChart, type ChartRow } from "@sheenui/theme";

export function Example() {
  const [rows, setRows] = useState<ChartRow[]>([]);
  useEffect(() => {
    // Your feed: one message per sample, e.g. { "rps": 812 }
    const socket = new WebSocket("wss://example.com/metrics");
    socket.onmessage = (event) => {
      const rps = Number(JSON.parse(String(event.data)).rps);
      setRows((r) => [...r.slice(-200), { time: Date.now(), rps }]);
    };
    return () => socket.close();
  }, []);
  return (
    <StreamingChart
      data={rows}
      series={[{ key: "rps", label: "Requests / s", color: 7 }]}
      rate={500}
      window={80}
      zero
      aria-label="Requests per second"
    />
  );
}
```

### When to use the real-time chart

- Use it as a live chart in React for an ops wall or a status page, such as requests per second and error rate over the last minute, where samples keep arriving and the line should glide along instead of redrawing.

### Frequently asked questions

#### How do I build a real time chart in React with SheenUI?

Call useStreamingData(source, options) in the small component that renders the card; it calls source every rate ms, 1000 by default, and keeps a rolling buffer. Pass the rows and series to StreamingChart. Each sample then re-renders only that card.

#### Can users pause the chart to read a value?

Yes. Hovering, tapping or arrowing holds the view still, and there is a built-in Pause button; Space or K toggles it from the chart. Data keeps arriving while paused, and Resume glides to the present. Use paused or defaultPaused to control it.

#### What does it do on prerendered pages?

Timestamps depend on the clock and the viewer's time zone, so pass timeZone and locale, and a fixed options.startAt, so server and browser histories match. Right after mount the history is rebuilt to end now.

#### How does it save work in the background?

With pauseWhenHidden on by default, no timer runs while the tab is hidden, and the missed samples are filled in when you return so the line stays continuous. Under reduced motion the chart redraws in place, with no sliding.

### When to use the sunburst chart

- Use it as a hierarchical pie chart for a bundle size breakdown, where packages sit in rings by folder and you need to see which branch of the hierarchy owns the weight.
- It fits cloud spend by team and service, or disk usage by folder, where clicking a group zooms into it with an animated sweep.
- It works for flat data too: without children it becomes a single ring like a donut, with every arc taking its own slot and tiny values still getting a hairline arc.
- Skip it when the hierarchy has many tiny leaves or readers must compare sizes precisely; Treemap uses area more efficiently, and a BarChart is better for exact comparison.
- Pair it with ChartCard for the title, SunburstTable for the nested text view with percent of parent and total, and onNodeClick to open details for a leaf.


### Frequently asked questions

#### How do I make a sunburst chart in React?

Pass nested data: leaves carry a value, groups carry children to any depth and add them up. Each node has a label and an optional color. Height defaults to 360 and the chart is a circle fitting the smaller of width and height.

#### How many rings are shown, and how do I zoom?

rings defaults to 3 levels at a time; deeper ones appear as you zoom. Click or press Enter on a group to zoom into it; the breadcrumb, the center, or Escape zoom back out. Use path, defaultPath and onPathChange to control the zoom.

#### How do I move around with the keyboard?

Left and Right move around the ring and wrap, Down goes out to the first child, Up back to the parent, and Home and End reach the first or last arc of the ring. Enter or Space zooms in, and Escape or Backspace zooms out one level.

#### Why are some arcs unlabeled?

Arcs too thin to hold a name stay unlabeled. Hover one to read it in the center, where the number rolls to its value, or find it in the tooltip and the SunburstTable. Reduced motion skips the sweep and the number roll.

- defaultWaffleChartLabels — The built-in English strings of WaffleChart; spread it into your own labels and change what you need.
- foldWaffleItems — More than 8 parts: the 7 largest keep their place (in your order) and their colour slot.
- waffleCells — Cells per part, by largest remainder so they add up exactly.
- waffleLegend — Legend for a waffle: each part's key, name and share, as the chart shows them.


### When to use the waffle chart

- Use it as a percentage grid chart to make a share land fast, such as sessions by device on a 10 by 10 grid where every cell is exactly one percent.
- It fits storage or quota displays on a part of a larger whole, such as 81.6 GB of 128 GB used, with total above the sum leaving the rest of the cells empty.
- The pictogram variant suits human-scale statistics, such as how 100 employees get to work, drawing any currentColor icon in each cell.
- Skip it when precision matters or there are more than a handful of parts; BarChart is more accurate, and Meter or Progress fits a single completion value.
- Pair it with ChartCard for the title and Chart / Table tabs, WaffleTable for the text twin, and NumberTicker to show the headline figure beside the grid.


### Frequently asked questions

#### How are cells assigned so they always add up?

Cells are split by largest remainder, so the counts always sum to the grid size even when percentages round awkwardly, and any part with a value keeps at least one cell. Negative values count as 0, and with more than eight parts the seven largest stay and the rest fold into Other.

#### Can I use a grid that is not 10 by 10?

Yes. rows and columns both default to 10, and any size works, such as 20 columns by 5 rows for a storage bar. fill chooses rows or columns order, and maxCell caps the cell size in px.

#### How do I make a pictogram waffle chart?

Set variant to pictogram and pass an icon, any ReactNode that draws with currentColor; the default is a person. Each cell shows the icon in its part's color, and hovering a cell or legend row lights up the whole part.

#### How do I navigate it without a mouse?

Focus the grid, then Right or Down moves to the next part (in right-to-left layouts Left takes Right's place), Left or Up to the previous, Home and End to the first or last part, and Escape stops reading. Changed data pops only the cells that change.
