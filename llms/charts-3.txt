### Example 1 of 2: Likert survey

Six statements, 460 answers each. Shares sit inside the segments where they fit (black or white ink, whichever reads better), and the net score follows each row. Switch the quarter and the segments morph. Up and down move between statements, left and right between answers.

```tsx
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
import { DivergingBarChart } from "@/components/sheenui/charts/diverging-bar-chart";
import { divergingLegend, type DivergingLevel } from "@/components/sheenui/charts/diverging-bar-chart/model";
import { DivergingBarTable } from "@/components/sheenui/charts/diverging-bar-chart/table";
// Package build (after the first npm release, or a packed tarball): import { ChartCard, divergingLegend, DivergingBarTable, DivergingBarChart, type DivergingLevel } from "@sheenui/theme";

const levels: DivergingLevel[] = [
  { key: "sd", label: "Strongly disagree" },
  { key: "d", label: "Disagree" },
  { key: "n", label: "Neutral" },
  { key: "a", label: "Agree" },
  { key: "sa", label: "Strongly agree" },
];
const data = [
  { statement: "The product is easy to learn", sd: 12, d: 30, n: 64, a: 214, sa: 160 },
  { statement: "It saves me time every week", sd: 9, d: 24, n: 51, a: 222, sa: 174 },
  { statement: "Support answers quickly", sd: 22, d: 48, n: 90, a: 196, sa: 124 },
];

export function Example() {
  return (
    <ChartCard
      title="Customer survey"
      legend={divergingLegend(levels)}
      table={<DivergingBarTable data={data} index="statement" levels={levels} indexLabel="Statement" caption="Survey answers" />}
    >
      <DivergingBarChart data={data} index="statement" levels={levels} aria-label="Survey answers, from strongly disagree to strongly agree" />
    </ChartCard>
  );
}
```

### Example 2 of 2: Population pyramid

variant="butterfly" with two levels: men to the left, women to the right of the spine, the age groups in the middle. One scale for both sides, so the halves compare honestly.

```tsx
import { DivergingBarChart } from "@/components/sheenui/charts/diverging-bar-chart";
// Package build (after the first npm release, or a packed tarball): import { DivergingBarChart } from "@sheenui/theme";

const population = [
  { age: "60+", men: 3_400_000, women: 4_100_000 },
  { age: "40–59", men: 4_900_000, women: 5_000_000 },
  { age: "20–39", men: 5_200_000, women: 5_100_000 },
  { age: "0–19", men: 4_300_000, women: 4_100_000 },
];

export function Example() {
  return (
    <DivergingBarChart
      variant="butterfly"
      data={population}
      index="age"
      levels={[
        { key: "men", label: "Men" },
        { key: "women", label: "Women" },
      ]}
      aria-label="Population by age group and sex"
    />
  );
}
```

### Accessibility

- The figure takes focus as one stop and is named by its aria-label, the chart title. A one-line hint explains the keys, and a ChartCard table view is linked through aria-details. Values are announced politely, once per move. Shares are printed as text and every Likert row has a net score, so color never carries the reading; each move announces the row and segment.
- DivergingBarTable is the table view: pair it with ChartCard's table prop (Chart / Table tabs) so every value can be read without color or sight.
- Reduced motion: the bars appear at their final lengths on either side of zero and data changes jump instead of morphing.

### All exports on this page

- DivergingBarChart — Bars that diverge from a midpoint.
- DivergingBarTable — Every row's count and share per level (plus the net score of a Likert row).
- defaultDivergingBarChartLabels — The built-in English strings of DivergingBarChart; spread it into your own labels and change what you need.
- divergingLegend — Legend items for a diverging chart, in level order (or the two sides of a butterfly).
- divergingLevels — Each level's side and colour: equal steps per arm, strongest at the extremes, a grey neutral.


### When to use the diverging bar chart

- Use the likert variant as a Likert scale chart for survey results, such as strongly disagree through strongly agree per question, with each row summing to 100 percent and a net score after it.
- Use the butterfly variant for a population pyramid or an A/B comparison, drawing two groups back to back from a central spine on one shared scale with row names down the middle.
- Use it for sentiment by product feature or NPS-style breakdowns, where positive and negative answers should pull to opposite sides of a neutral midpoint.
- Skip it when the categories are not ordered or have no meaningful midpoint, because a Bar chart or Percent bar chart fits unordered parts of a whole better.
- Pair it with ChartCard and DivergingBarTable for a text view, ChartLegend to explain the answer levels, and a Select to switch the survey wave.


### Frequently asked questions

#### How do I make a diverging bar chart for Likert data in React?

Pass data rows with an index key, then levels from most negative to most positive. With an odd count the middle level is neutral and straddles the center line, or set neutral to a key. negativeColor and positiveColor pick the two poles.

#### How do I draw a population pyramid?

Set variant to butterfly and give exactly two levels, which draw left and right of the spine. colors takes a pair of palette slots, defaulting to 7 and 5. Set normalize to show each side's share of the grand total instead of raw counts.

#### Does it rely on color to carry the meaning?

No. Shares are printed inside segments where they fit, and each Likert row ends with a net score of positive minus negative, controlled by showNet. The group is named by aria-label, and keyboard moves announce the row and segment.

#### Which keys move between rows and segments?

Tab focuses the chart. Up and Down move between rows, Left and Right move between a row's segments, Home and End jump to the first and last row, and Escape clears. Under reduced motion segments draw and morph instantly rather than sweeping out from the center.

### Example 2 of 2: Lower is better, with dash patterns

higherIsBetter={false} ranks the smallest number first, here the median response time per channel. patterns gives each line its own dash style, so the lines differ without colour; it turns on by itself from four series.

```tsx

  { key: "chat", label: "Chat" },
  { key: "email", label: "Email" },
  { key: "phone", label: "Phone" },
  { key: "social", label: "Social" },
];

  { month: "Jan", chat: 4, email: 190, phone: 22, social: 95 },
  { month: "Mar", chat: 7, email: 120, phone: 21, social: 61 },
```

### Accessibility

- The chart is a focusable figure named by its aria-label (the chart title), with the keyboard hint as its description and, inside a ChartCard with a table view, aria-details pointing at that table. Moving through it announces the series, the period, its rank and how far it moved, politely, once.
- The rank is written in each dot and the series name at the end of its line, and from four series on every line gets its own dash style (patterns), so colour never identifies a series.
- BumpTable is the table view: one row per period, one column per series, each cell its rank and value.
- Reduced motion: the lines and dots appear at once and data changes jump instead of gliding.

### All exports on this page

- BumpChart — A bump chart: how the ranking of several series changes over time.
- BumpTable — Every point in time with each series' rank (and its value), one column per series.

### When to use the bump chart

- Use it for league tables and leaderboards over time, such as sales regions ranked by revenue each quarter, where who is ahead matters more than by how much.
- Use it for top-N lists that reshuffle: search rankings, product popularity, support channels by response time. Set higherIsBetter to false when a smaller number ranks higher.
- Pass ready-made ranks with rankBy="rank" when your data already holds positions, and highlight one series to tell the story of a single climber or faller.
- Skip it when the size of the values matters, where a Line chart shows the gap between series, or with more than about ten series, where the lines cross too often to follow.
- Pair it with ChartCard, bumpLegend and BumpTable for the legend, the Chart / Table tabs and a text version of every rank.


### Frequently asked questions

#### How do I make a bump chart in React?

Pass data as one row per point in time with a number per series, index as the key that names the row, and series as { key, label } entries. Ranks are computed per row, so the highest value ranks first. aria-label is required.

#### Can I use ranks I already have?

Yes. Set rankBy to rank and the numbers are taken as positions, 1 being the best. With rankBy value, higherIsBetter decides whether a larger number ranks higher; ties keep the series order, so every rank is used once.

#### How are the lines told apart without colour?

The rank is written in each dot and the series name at the end of its line. From four series on, patterns gives every line its own dash style as well. Inside a ChartCard the legend hides a series and the rest are re-ranked.

#### How does keyboard use work?

Tab focuses the chart. Left and Right move through time, Up and Down move to the series one rank higher or lower, Home and End jump to the first and last point, Escape clears. Each move announces the series, period, rank and how far it moved.

### Accessibility

- The chart is a focusable figure named by its aria-label (the chart title), with the keyboard hint as its description and, inside a ChartCard with a table view, aria-details pointing at that table. Moving through it announces each item, its estimate and both ends of its interval.
- The interval is a drawn whisker with end caps (or a dashed-edged band), a shape rather than a colour, and its ends are printed as numbers in the tooltip and in ErrorBarTable.
- Reduced motion: bars, whiskers and the band appear at once and data changes jump instead of gliding.

### All exports on this page

- ErrorBarChart — An error bar chart: an estimate for each item with the interval around it, drawn as a whisker.
- ErrorBarTable — Every item with its estimate and the lower and upper end of its interval.
- defaultErrorBarChartLabels — The built-in English strings of ErrorBarChart; spread it into your own labels and change what you need.


### When to use the error bar chart

- Use it for A/B test results, survey estimates and model scores, where how sure a number is matters as much as the number: each bar or dot carries a whisker from the low to the high end of its interval.
- Use variant="point" with a reference line for effect sizes in the forest-plot style, so any whisker that crosses the line reads as no clear difference.
- Use variant="band" for a forecast or a measurement over time: a line of estimates with the confidence interval shaded around it, widening as the future gets less certain.
- Skip it when you have the raw observations, where a Box plot or Beeswarm shows the whole distribution, or when every value is exact and there is no interval to draw.
- Pair it with ChartCard, errorBarLegend and ErrorBarTable so the card gets a legend, a Chart / Table switch and a text version of every interval.


### Frequently asked questions

#### How do I add confidence intervals to a bar chart in React?

Pass data as items with label, value, low and high. Each bar gets a whisker with end caps from low to high, and the tooltip and table print both ends. Name the interval with intervalLabel, for example 95% CI. aria-label is required.

#### How do I draw a confidence band on a line?

Set variant to band. The items become the points of a line through value, with the area between low and high shaded and dashed at its edges. Use height to size it; categories sit evenly along the x axis, so keep them in order.

#### Can I show a no-effect line?

Yes. reference takes { value, label } and draws a dashed line with its label, for example 0 for no change. baseline sets where bars start, and the scale always covers every interval, the baseline and the reference.

#### How does keyboard use work?

Tab focuses the chart. Up and Down move between bars and points, Left and Right between the points of a band, Home and End jump to the first and last, Escape clears. Each move announces the estimate and both ends of the interval.

### When to use the dumbbell and slope chart

- Use it as a before and after chart for year-over-year comparisons across named items, such as revenue per product in 2024 against 2025, where the size and direction of each change is the story.
- Use the slope variant for ranking shifts between two points in time, with the two ends in columns, lines joining them and labels spread so none collide.
- Sort by change to put the biggest rise first, and set higherIsBetter to false for costs or churn so the status color of each change is not misleading.
- Skip it when you have more than two time points per item, where a Line chart shows the whole path, or when you compare totals rather than change, where a Bar chart is enough.
- Pair it with ChartCard and DumbbellTable for a text view, plus a SegmentedControl to switch between the dumbbell and slope variants or between absolute and percent change.


### Frequently asked questions

#### How do I build a React dumbbell chart?

Pass data as items with label, from and to, then fromLabel and toLabel such as 2024 and 2025. A light before dot and a full-color after dot are joined by a bar that brightens in the direction of travel. aria-label is required.

#### How are increases and decreases shown without color alone?

Each change is printed with an up or down arrow and a success or danger tone chosen by higherIsBetter. The change prop picks absolute, percent or none. So a rise in churn reads as bad both by tone and by the arrow and sign text.

#### Can I switch to a slope chart or re-sort the items?

Set variant to slope for two columns joined by lines. sort takes none, to, from or change, and re-sorting slides the rows to their new places. highlight takes one label or several and grays out the others. height applies to the slope variant only.

#### How does keyboard use work?

Tab focuses the chart, Up and Down move between items, Home and End jump to the first and last, and Escape clears. Rows are plain SVG moved by one frame loop, and reading a row never re-renders the others. Reduced motion draws, glides and re-sorts instantly.

- Use it as a project timeline chart: a plan with tasks as bars on a timeline, progress fills, finish-to-start dependency arrows, milestones and a today line, such as a product launch schedule.

### Frequently asked questions

#### How do I build a Gantt chart in React with dependencies?

Pass tasks, each with a unique id, label and start, plus optional end, progress from 0 to 1, group and assignee. dependencies lists the ids that must finish first, drawn as finish-to-start arrows. A milestone true task marks a single day as a diamond.

#### Is the end date inclusive?

Yes. end is the last day, so a task from the 2nd to the 6th covers five days. Date strings like 2026-03-02 are read as local dates and never shifted by time zones. For milestones, end is ignored.

#### Which keys work on the timeline?

Tab focuses it. Up and Down move between tasks, Left and Right scroll, mirrored in right-to-left, Home and End jump to the first and last task, T jumps to today, plus and minus zoom, and Escape clears. Enter calls onTaskClick, and toolbar buttons are normal tab stops.

#### Does a long plan widen the page on a phone?

No. The task names stay put while the timeline scrolls sideways inside its own container, with an edge fade while more plan lies beyond it. Short plans stretch to fill the width. labelWidth sets the name column width, and today moves or hides the today line.

### When to use Heatmap

- Use it as a matrix heatmap for a category-by-category grid, such as traffic by weekday and time of day, error counts by service and hour, or feature usage by plan, where color encodes the value. Use it for a correlation heatmap by putting the variables on both axes and the coefficient in each cell.

- Use it when some cells have no data: missing values are hatched, never painted as zero, so a gap in a metric is not mistaken for a real low reading.

### Frequently asked questions

#### How do I build a react heatmap from rows and columns?

Pass data as one object per row, index with the key of the row label, and columns listing each value key and label. Add aria-label. The color prop picks a palette slot from 1 to 8 for the single-hue ramp, and domain overrides the scale range.

#### How are missing values shown?

Cells with a missing or non-numeric value are hatched and read No data, never painted as zero. Values given as numeric strings are parsed. Set showValues to print each value inside its cell when the cell is big enough to fit it.

#### What happens on narrow screens?

Columns shrink down to minCellWidth, 12px by default. Past that, the grid scrolls sideways inside its own focusable container while the row labels stay put. cellHeight overrides the row height, which otherwise follows the cell width between 24 and 40 px.

#### Which keys move between cells?

Focus the grid and use the arrow keys. Home and End move along a row, Ctrl+Home and Ctrl+End go to the corners, Escape clears, and Enter or Space calls onCellClick. The bloom-in wave and the cross-fade on new data are instant with reduced motion.

### Frequently asked questions

#### How do I make a histogram in React from raw values?

Pass values as the raw numbers, such as every latency, plus aria-label. Non-finite values are ignored. Bins default to auto, picked by Freedman-Diaconis or Sturges, and niceBins snaps the edges to round numbers so the bin count lands near what you asked for.

#### Can I set my own bin count or rule?

bins takes a number or one of auto, sturges, freedman-diaconis or scott. domain limits the range that is binned, and values outside it are left out. New data or a new bin count morphs the bars rather than redrawing them.

#### How do I add percentile lines?

markers takes median, mean, p90, p95, p99 or an object with a value and a label. Each draws a reference line on the chart. density overlays a Gaussian kernel density curve, and bandwidth overrides its default, which follows Silverman's rule.

#### How do keyboard users read the bins?

Tab focuses the chart, then Left and Right (mirrored in right-to-left) or Down and Up move between bins. Home and End jump to the ends and Escape clears. Each move announces the bin's range, count, share and cumulative share at or below it.
