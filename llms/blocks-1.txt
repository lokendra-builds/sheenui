#### Frequently asked questions

#### What is a block?

A block is a ready-made section or screen, such as a login form, a pricing table or an AI chat, assembled only from SheenUI components so it matches the rest of your interface.

#### How do I add a block to my project?

Every block page lists its files to copy, and the registry installs it with one shadcn command. The installation page shows the steps.

#### Can I change the blocks?

Yes. They are plain React source in your repository, with Tailwind classes you can edit; nothing is hidden in a package.

### Example 1 of 2: Sign in

Try submitting empty, then with any email and an 8+ character password.

```tsx
import { GlassLogin } from "@/components/sheenui/blocks/glass-login";
// Package build (after the first npm release, or a packed tarball): import { GlassLogin } from "@sheenui/theme";

// Your auth calls; signIn throws on failure so the card shows the error
async function signIn(email: string, password: string) {
  const res = await fetch("/api/sign-in", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ email, password }),
  });
  if (!res.ok) throw new Error("Wrong email or password");
}

function startOAuth(provider: "github" | "google") {
  window.location.assign("/auth/" + provider);
}

export function Example() {
  return (
    <GlassLogin
      onSubmit={async ({ email, password }) => {
        await signIn(email, password);
      }}
      onSocial={(provider) => startOAuth(provider)}
    />
  );
}
```

### Example 2 of 2: Your copy, a stricter rule, a failing sign-in

Change the heading and the line under it, require 12 characters, hide the sign-up link and leave out the social buttons (they only show when onSocial is given). This one always fails, so you can see the error.

```tsx
import { GlassLogin } from "@/components/sheenui/blocks/glass-login";
// Package build (after the first npm release, or a packed tarball): import { GlassLogin } from "@sheenui/theme";

<GlassLogin
  title="Sign in to Acme"
  subtitle="Use your work email."
  minPasswordLength={12}
  signUpHref={null}
  onSubmit={async () => {
    throw new Error("Wrong email or password"); // the card shows the error and stays editable
  }}
/>
```

### When to use the glass login form

- Use GlassLogin as a glassy login page for a SaaS dashboard, where one frosted card with email, password and a forgot-password link sits over an aurora or gradient background. Use it as a liquid glass login form when the sign-in screen sits over a SheenBackdrop.
- Use it inside a modal or drawer when a signed-out visitor clicks a gated action, such as saving a design or posting a comment, and you want sign-in without leaving the page.
- Use it for an internal admin tool that needs only email and password plus optional GitHub and Google buttons, with the built-in strings translated through the labels prop and the heading through title and subtitle.
- Skip it when sign-up and sign-in share one screen with a brand panel and password-strength feedback; AuthSplit covers that layout, while GlassLogin only links out to a sign-up page.
- Pair it with SheenBackdrop for the aurora behind the card, the Input component for any extra fields you add around it, and useSheenReducedMotion if you animate the page behind the card.


### Frequently asked questions

#### How do I build a glassmorphism login form in React with GlassLogin?

Import GlassLogin from @sheenui/theme and pass onSubmit, which receives { email, password }. Return a promise to show the button loading state, or throw an Error to display its message under the form. Add onSocial(provider) to reveal the GitHub and Google buttons, which stay hidden without it.

#### How does GlassLogin validate the email and password?

It renders a real form with noValidate and runs its own checks on submit. A malformed email or a password shorter than minPasswordLength (default 8) shows visible error text linked with aria-describedby, and focus moves to the first invalid field. Change the messages through the labels prop, including the shortPassword function.

#### Can I translate or rename the text in the login card?

Yes, every user-facing string lives in GlassLoginLabels: field labels, the show and hide password names, the divider, the submit text and the error messages. Pass a partial labels object and it is merged over defaultGlassLoginLabels, so you only override the strings you change. title and subtitle accept any ReactNode.

#### Does the login block work with Next.js and reduced motion?

The file starts with "use client", so import it from a client component or a route that renders one. The loading state and hover fades use the shared motion tokens, and reduced motion and reduced transparency preferences are honored. Targets grow to 44 px on touch devices.

### Accessibility

- The cord is a real toggle button named by labels.cord; its pressed state says whether the light is on. The hint under the lamp is text.
- The card is always in the page and in tab order. The lamp, cone and dimming layer are aria-hidden: nothing is said by light alone.
- The stage is forced dark, so the glass and its text keep at least 4.5:1 contrast whatever the page theme.
- Reduced motion: the light starts on, the cord does not swing and the cone does not grow; pulling it still changes the light with a short fade.

### When to use the lamp login form

- Use LampLogin as an animated login page for a product that wants one memorable first impression: a dark stage, a lamp with a pull cord, and a sign-in card that the light reveals.
- Use it for a portfolio, a game or a creative tool where the sign-in screen is part of the brand, and the form itself still needs real validation, a loading state and error messages.
- Use lit, defaultLit and onLitChange when the surrounding page needs to know whether the light is on, for example to start the stage already lit after a failed sign-in.
- Skip it for a plain admin sign-in where speed matters more than delight; GlassLogin is the same form without the stage.
- Pair it with GlassLogin options such as onSocial and forgotHref, which it passes straight through, and with useSheenReducedMotion if you add motion of your own around it.


### Frequently asked questions

#### How do I build a pull-cord lamp login in React?

Render LampLogin from @sheenui/theme with an onSubmit that receives { email, password }. Pulling the cord (click, Enter, Space, or a drag down on touch) switches the light on and reveals the card. Return a promise from onSubmit to show the loading state, or throw to show an error.

#### Can keyboard and screen-reader users sign in without pulling the cord?

Yes. The card is always in the page and in tab order; the light is only a look. The cord is a real toggle button named by labels.cord, and focus entering the card switches the light on, so nobody types into the dark.

#### What happens with reduced motion?

The light starts on, the cord does not swing and the cone does not grow. Pulling the cord still switches the light with a short fade.

#### Can I translate the text?

Yes. labels holds the cord name and the two hints, and loginLabels holds every string of the card (it is a GlassLogin). Pass partial objects and they are merged over the English defaults.

### Example 2 of 3: Real streaming and history

Return an async iterable to stream tokens as they arrive. This one continues an earlier conversation, uses its own assistant name and models, and turns attachments off.

```tsx
import { AiChat } from "@/components/sheenui/blocks/ai-chat";
import { type AiChatMessage } from "@/components/sheenui/blocks/ai-chat/types";
// Package build (after the first npm release, or a packed tarball): import { AiChat, type AiChatMessage } from "@sheenui/theme";

// An earlier conversation, e.g. loaded from your database
const savedMessages: AiChatMessage[] = [
  { id: "h1", role: "user", content: "How do I debounce a search field in React?" },
  {
    id: "h2",
    role: "assistant",
    model: "nova-large",
    content: "Keep the input instant and debounce the **value** you search with, then fetch with the debounced value instead of the raw one.",
  },
];

export function Example() {
  return (
    <AiChat
      defaultMessages={savedMessages}
      models={[
        { value: "nova-large", label: "Nova Large", description: "Most capable" },
        { value: "nova-small", label: "Nova Small", description: "Fastest" },
      ]}
      allowAttachments={false}
      labels={{ assistant: "Nova", placeholder: "Ask Nova…" }}
      respond={async function* ({ messages, model, signal }) {
        const res = await fetch("/api/chat/stream", { method: "POST", body: JSON.stringify({ model, messages }), signal });
        const reader = res.body!.pipeThrough(new TextDecoderStream()).getReader();
        for (;;) {
          const { value, done } = await reader.read();
          if (done) return;
          yield value; // each chunk is appended as it arrives
        }
      }}
    />
  );
}
```

### When to use the bento grid

- Use BentoGrid as a glassmorphism bento grid for a landing page feature section, where cells of different sizes show a chart, a notification stack, an OTP field and a switch preview instead of a plain three-column list. Use it as a bento features section in Tailwind on a landing page.
- Use it for a product overview inside a documentation site, giving big cells colSpan 2 or rowSpan 2 and letting the grid collapse to one column on narrow containers.

### Frequently asked questions

#### How do I make a bento grid in React with BentoGrid and BentoCell?

Wrap BentoCell children in BentoGrid. Each cell takes a required title, plus description, icon, visual, colSpan, rowSpan, href and cta. Use className for the container and gridClassName for gap and row height. The cells carry their own headings, and the grid adds no semantics.

#### How many columns does the grid use on small screens?

It follows its own width, not the viewport: one column by default, two from 36rem and three from 56rem. Cell spans shrink on the way down so nothing overflows. That means a grid placed in a narrow sidebar also stacks correctly without media queries on your side.

#### Does a bento cell load its visual before the user scrolls to it?

No. The visual prop is mounted the first time the cell scrolls into view, so cells nobody reaches cost nothing. Decorative visuals should be aria-hidden. The card itself rises in with a stagger set by index, and reduced motion only fades.

#### Which keyboard stops does a bento cell add?

Only the optional link. When you pass href and cta, that link is the single tab stop the cell adds. The demo visuals have their own controls: the chart's period pills are a radio group with arrow-key navigation, and the switch demo uses Space to toggle each switch.

### Example: Messenger

Open chats, send messages (replies arrive with typing and read receipts), pin or archive from a row's menu, and open the info panel from a chat's header. Narrow your window (or open this on a phone) to see the stacked layout.

```tsx
import { useState } from "react";
import { ChatApp } from "@/components/sheenui/blocks/chat-app";
import { type ChatConversation, type ChatConversationAction, type ChatDraft, type ChatMessage, type ChatParticipant } from "@/components/sheenui/chat/types";
// Package build (after the first npm release, or a packed tarball): import { ChatApp, type ChatConversation, type ChatConversationAction, type ChatDraft, type ChatMessage, type ChatParticipant } from "@sheenui/theme";

// Your data layer: replace these with real data and handlers.
declare const chats: ChatConversation[];
declare const people: ChatParticipant[];
declare const messagesById: Record<string, ChatMessage[]>;
declare const cursors: Record<string, string | null>;
declare function loadOlder(chatId: string): void;
declare const api: {
  send(chatId: string, draft: ChatDraft): void;
  edit(messageId: string, text: string): void;
  delete(messageId: string): void;
  react(messageId: string, emoji: string, add: boolean): void;
  markRead(chatId: string): void;
  updateChat(chatId: string, action: ChatConversationAction): void;
  block(personId: string): void;
};

export function Example() {
  // Keep the open chat in the URL (?chat=c-riya) so it can be linked to.
  const [chatId, setChatId] = useState<string | undefined>(() => new URLSearchParams(location.search).get("chat") ?? undefined);

  return (
    <ChatApp
      conversations={chats}
      participants={people}
      currentUserId="me"
      messages={messagesById}
      selectedId={chatId}
      onSelectedIdChange={(id) => setChatId(id ?? undefined)}
      hasOlder={(id) => cursors[id] !== null}
      onLoadOlder={(id) => loadOlder(id)}
      onSend={(id, draft) => api.send(id, draft)}
      onEdit={(id, messageId, text) => api.edit(messageId, text)}
      onDelete={(id, message) => api.delete(message.id)}
      onReact={(id, message, emoji, add) => api.react(message.id, emoji, add)}
      onRead={(id) => api.markRead(id)}
      onConversationAction={(chat, action) => api.updateChat(chat.id, action)}
      onBlock={(person) => api.block(person.id)}
      className="h-[44rem]"
    />
  );
}
```

### Accessibility

- The list and the chat are labeled regions. Focus is managed on every pane change: opening a chat on a phone moves it to the chat's name, going back returns it to the row, and a keyboard open on a wide layout lands in the composer.
- New messages and typing are announced politely (aria-live); message status (sending, sent, delivered, read, failed) is written text, not color alone, and presence is written in words.
- The info panel is a side drawer (a modal dialog with a focus trap); swipe and hover actions all have keyboard and menu equivalents, so nothing is gesture-only.
- Reduced motion makes the pane slide a jump; reduced transparency makes the glass panes solid; the message area never uses blur, so scrolling stays fast.

### When to use the chat app

- Use ChatApp as a messenger UI for a messaging screen in a marketplace or support tool, where a conversation list sits beside the open chat on wide containers and stacks on narrow ones.
- Use it for a team inbox with direct messages and groups, wiring onSend, onEdit, onDelete, onReact and onRetry to your backend while you hold the messages map in state.
- Use it when contact info matters, since opening a chat's info drawer shows avatar, about, phone, email, members, shared photos, and mute and block or leave actions.
- Skip it when you only need a floating help bubble on a marketing page; ChatWidget is lighter, and AiChat fits a person talking to a model rather than to other people.
- Pair it with ConversationList and ChatThread when you want a custom layout from the same parts, and with EmptyState and SideDrawer for screens around the chat.


### Frequently asked questions

#### How do I get a React chat app template running with ChatApp?

Pass conversations, participants, currentUserId and a messages map from chat id to message array; all four are required. Give the block a height with className, and handle onSend(conversationId, draft) to store the message. selectedId or defaultSelectedId chooses the open chat.

#### When does ChatApp switch from two panes to one?

It stacks below a container width set by stackBelow, 640 by default, measured on the block itself and not the screen. On narrow widths the chat slides over the list with a back button. Reduced motion turns the slide into a jump, and reduced transparency makes the glass solid.

#### How is keyboard focus handled when opening and closing chats?

In the list, arrow keys move between chats and Enter opens one. On a wide layout, opening a chat with the keyboard moves focus to the composer; on a phone it moves to the chat name, and going back returns it to the chat's row. Escape closes the info drawer, and Enter sends while Shift plus Enter adds a line.

#### Why is the message area not blurred glass?

The list, chat header and composer are glass panes, but the scrolling message area is deliberately not, because blur is kept off scrolling content. Message status such as sent, delivered or failed is shown as text rather than color alone, and new messages and typing are announced politely.

### Example 1 of 3: Bell and inbox

Open the bell, then try “Simulate a notification”: the bell rings, the count pops and the new row glows once. Hover a row for its actions, accept the invite, or press Delete on a focused row (Undo or ⌘Z / Ctrl+Z brings it back). On a phone the inbox opens as a sheet from the bottom of the screen.

```tsx
import { useState } from "react";

import { NotificationCenter } from "@/components/sheenui/blocks/notification-center";
import { type NotificationItem } from "@/components/sheenui/blocks/notification-center/model";
// Package build (after the first npm release, or a packed tarball): import { NotificationCenter, type NotificationItem } from "@sheenui/theme";

const router = { push: (to: string) => window.location.assign(to) };

const api = {
  deleteNotification: (id: string) => fetch("/api/notifications/" + id, { method: "DELETE" }),
};

export function Example() {
  const [items, setItems] = useState<NotificationItem[]>([
    {
      id: "n1",
      kind: "mention",
      actor: { name: "Ada Lovelace", avatar: "/ada.jpg" },
      title: <><b>Ada Lovelace</b> mentioned you in <b>Q3 roadmap</b></>,
      description: "“@you could you sanity-check the contrast numbers?”",
      time: "2026-10-30T09:41:00Z",
      href: "#demo-q3-roadmap-c12",
    },
    // …
  ]);

  return (
    <NotificationCenter
      notifications={items}
      onNotificationsChange={setItems}
      onSelect={(n) => {
        if (n.href) router.push(n.href);
      }}
      // Delete on the server once Undo is no longer possible.
      onDismissCommit={(n) => api.deleteNotification(n.id)}
      viewAllHref="/notifications"
    />
  );
}
```

### When to use the notification center

- Use NotificationCenter as a notification dropdown for the bell in an app header, where an unread count badge opens a popover inbox with All, Unread and Mentions tabs and, with viewAllHref, a link to view everything.
- Use NotificationPanel for a dashboard column or a drawer that shows the inbox inline, giving it a height with className because it defaults to 32rem.
- Use it when dismissals need a safety net, since Delete removes a notification, an undo bar appears, and Ctrl or Cmd plus Z restores it.
- Skip it when you only need a brief confirmation such as "Saved"; a Toast fits transient messages better than a persistent inbox with read state and tabs.
- Pair it with Avatar for sender images, Tooltip for the header actions, and KbdShortcut to teach the undo shortcut, passing items through notifications or defaultNotifications.


### Frequently asked questions

#### How do I build a notification center in React with this block?

Render NotificationCenter with defaultNotifications, or notifications plus onNotificationsChange for controlled state. Handle onSelect for opening an item and onDismiss for removal. Use NotificationPanel instead when you want the same inbox inline without the bell. Each item needs an id, title and time; kind, actor and description are optional.

#### What does the bell announce to screen readers?

The bell button is named something like "Notifications, 3 unread", and the count is real text. The count caps at max, which defaults to 99. Arrivals, dismissals, the undo shortcut and "all read" are announced politely, and the panel itself is a labeled popover that returns focus on Escape.

#### Which keys work inside the notification list?

Tab enters the tabs and then the list. Up, Down, Home and End move between notifications, Enter opens one, and Delete dismisses it while focus moves on. Ctrl or Cmd plus Z undoes a dismissal. Swipe-to-dismiss on touch always has a dismiss button as an alternative.

#### Can I control where the popover opens and whether it is open?

Yes. Use open, defaultOpen and onOpenChange for control, side (default bottom) and align (default end) for placement, and panelClassName to style the portaled glass card. The bell rings when something new arrives, except when the visitor prefers reduced motion.
