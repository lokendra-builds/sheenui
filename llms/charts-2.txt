### Example 1 of 2: Top referrers, top 5

Shows the top five; “Show more” reveals the rest without rescaling the bars, since every bar shares the list's largest value. Rows are buttons here: click or press Enter to filter by a source.

```tsx
import { useState } from "react";
import { BarListTable, BarList, type BarListItem } from "@/components/sheenui/charts/bar-list";
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
// Package build (after the first npm release, or a packed tarball): import { ChartCard, BarListTable, BarList, type BarListItem } from "@sheenui/theme";

const referrers: BarListItem[] = [
  { name: "Searchly", value: 4821 },
  { name: "Direct", value: 3207 },
  { name: "codehost.example", value: 1342 },
  { name: "Hacker News", value: 655 },
  { name: "Lookup", value: 287 },
  { name: "Newsletter", value: 214 },
];

export function Example() {
  const [filter, setFilter] = useState<string | null>(null);
  return (
    <ChartCard title="Top referrers" description={filter ? "Filtered by " + filter : "All sources"} table={<BarListTable data={referrers} />}>
      <BarList
        data={referrers}
        limit={5}
        showShare
        nameHeader="Source"
        valueHeader="Visitors"
        onValueChange={(item) => setFilter(item.name)}
        aria-label="Visitors by referrer"
      />
    </ChartCard>
  );
}
```

### Example 2 of 2: Top pages, linked and re-ranked

Each row is a link (the whole row is its hit area) with an icon. Switch the range: rows glide to their new rank and bars resize, with transform-only animation that's instant under reduced motion. Where a short bar would end inside a name, its solid end becomes two ticks above and below the text.

### Keyboard

| Keys | Action |
| --- | --- |
| Tab | Move to each row that is a button (onValueChange) or a link (href), and to “Show more”. A plain list has no tab stops. |
| Enter / Space on a button row | Activate it (for example, filter by that row). |
| Enter on a link row | Follow the link. |
| Enter / Space on Show more | Reveal the remaining rows. |

### Accessibility

- The list is a real <ul>, so screen readers read each row's name, value and (with showShare) share as text. aria-label names the list and is required.
- Interactive rows have a solid inset focus ring and are ordinary tab stops.
- For a non-visual reading, give ChartCard's table prop a BarListTable; the Chart / Table tabs then expose each value as plain table cells.
- Under reduced motion nothing morphs: the bars render at their final lengths and new data replaces the old at once.

### All exports on this page

- BarList — A ranked list with each value drawn as a soft bar behind its label (Tremor style): the most compact way to compare many named values.
- BarListTable — Every row with its value and share of the total, in the list's order.
- defaultBarListLabels — The built-in English strings of BarList; spread it into your own labels and change what you need.


### When to use the bar list

- Use it as a ranked list chart for a top-referrers or top-pages card in an analytics dashboard, where five to ten named rows need a visible size comparison but a full bar chart would eat the whole card. It works as a tremor bar list alternative: ranked horizontal bars with a text table behind them.
- Use it for ranked leaderboards such as best-selling products, busiest API endpoints or support tickets by team, with a Show more button once you set limit so the card stays short.
- Make rows interactive when the list doubles as a filter: onValueChange turns each row into a button that sets a dashboard filter, while an item with an href becomes a link (onValueChange wins if you set both).
- Skip it when the values change over time or the categories have no natural ranking, because a Bar chart or Line chart shows trends and groups far better than a sorted list does.
- Pair it with ChartCard and BarListTable so the card gets a chart and table switch, and with SegmentedControl to flip the same list between a 7-day and 30-day range.


### Frequently asked questions

#### How do I build a react bar list with only the top 5 rows?

Pass limit={5}. BarList renders the first five rows after sorting and adds a Show more button for the rest. All bars share one scale, the largest value in the whole list, so revealing hidden rows never rescales the bars you already see.

#### Is the bar list accessible to screen readers?

It renders a real ul of rows, so assistive tech reads name, value and, with showShare, the share of the total as plain text. aria-label is required. Rows that are buttons or links are normal tab stops: Enter or Space activates a button, Enter follows a link.

#### Can I change the number format, locale or button text?

Yes. format and formatPercent replace the defaults, which are compact numbers and percentages in locale (default en). The labels prop overrides the Show more, Show less and of total strings, and you can spread defaultBarListLabels into your own object for translation.

#### What happens with negative values and reduced motion?

Negative values draw no bar. With prefers-reduced-motion the grow-in on first scroll into view and the glide when new data re-ranks the rows are both skipped, so bars and rows change instantly.

### When to use the beeswarm chart

- Use it as a swarm plot to show how every order value, response time or salary is distributed per group, when a box plot would hide the individual points that explain a long tail.
- Use it for a few hundred observations split by region or plan, with each row getting its own swarm and a median line, so readers can spot clusters and outliers in one glance.
- Color dots by series when a second category matters, for example plan tier inside each region; up to eight series keep their own palette slot and the rest fold into a gray Other.
- Skip it when you have thousands of points or only need summary statistics, because a Histogram or Box plot summarizes large samples without relying on individual dots being readable.
- Pair it with ChartCard and BeeswarmTable for a table view, ChartLegend to explain the series colors, and a Select to switch which grouping drives the rows.


### Frequently asked questions

#### How do I make a beeswarm chart in React with grouped rows?

Pass data as an array of points, each with a value and an optional group, label and series key, plus an aria-label. Points sharing a group share a row; points without one share a single row. Use the groups prop to set row order.

#### How do keyboard users read individual dots?

Tab focuses the chart, then the arrow keys along the value axis step between dots in value order. Up and Down jump to the nearest value in the next row when there are several groups, Home and End jump to the ends, and Escape clears the readout.

#### Does it stay fast with many dots?

Dots are plain SVG circles moved by one frame loop, and reading a dot does not re-render them. New data lays out in the background. Dense swarms shrink the radius toward 3px, and very dense swarms cross-fade on a data change rather than gliding every dot.

#### Can I highlight a few points and hide the median line?

Yes. highlight takes labels or ids of the points to emphasize while the rest step back, and showMedian (default true) can be set to false to remove the per-row median line. Give points a stable id so they glide to new positions when data changes.

### When to use the box plot and violin chart

- Use it as a box and whisker chart to compare latency, session length or delivery time across plans or regions, where the middle 50 percent, the median and the outliers matter more than any single average.
- Use the violin variant when the shape of each distribution matters, such as a bimodal response-time pattern, since it draws a kernel density around a slim box instead of just five numbers.
- Feed it precomputed statistics through the summary field when your backend already returns quartiles, whiskers and sample size, so the browser does not need the raw sample.
- Skip it when you have a single group, where a Histogram shows the distribution directly, or when every individual observation should stay visible, which a Beeswarm handles better.
- Pair it with ChartCard and BoxPlotTable, which lists n, quartiles, median, mean and outliers as text, and with a SegmentedControl to switch between the box and violin variants.


### Frequently asked questions

#### How do I draw a box plot in React from raw values?

Give each group a label and a values array, then set aria-label. BoxPlot computes the quartiles, whiskers and outliers for you. The whisker reaches 1.5 IQR by default, following Tukey, and points beyond it become outlier dots; set whisker to minmax to reach the extremes.

#### What is the difference between the box and violin variants?

variant box draws the box and whiskers. variant violin draws each group's kernel density as a mirrored shape around a slim box and needs raw values, not summaries. The bandwidth prop overrides the default, which follows Silverman's rule per group.

#### How does keyboard navigation work?

Tab focuses the chart. Arrow keys along the group axis move between groups, and arrows along the value axis step through the focused group's outliers. Home and End jump to the first and last group, Escape clears, and each move announces the group's statistics.

#### Will the chart rotate on small screens?

With orientation auto it draws upright boxes and turns them sideways when the chart is narrow or the group names would not fit under the boxes. Sideways charts grow in height with the number of groups, while height only controls the upright layout.

### Frequently asked questions

#### How do I make a bullet chart in React with a target and ranges?

#### Should rows share one scale?

#### Can I hide the delta or the ticks?

Yes. showDelta controls the delta against the target under each value and ticks controls the printed scale ticks. Both are booleans on BulletChart. Under reduced motion the bars are drawn in place without animation, and labels lets you translate the range names and other built-in strings.

### Frequently asked questions

#### How do I build a calendar heatmap in React?

Pass data as entries like date 2026-03-04 and value 12, then set year or a start and end range, plus aria-label. Days without an entry count as 0. The week starts where the locale's week starts, and weekStart overrides it with 0 for Sunday through 6.

#### How are future days handled?

Days after the today prop have not happened, so they are drawn as empty outlines and read No data yet instead of zero, unless data has a value for them. today defaults to the current date, and null removes the limit entirely.

#### Can keyboard users move through the days?

Focus the calendar, then Up and Down move a day, Left and Right move a week, Page Up and Page Down move a month, and Home and End jump to the first and last day. Enter or Space calls onDayClick for the focused day.

#### How do I control the color levels?

levels sets the number of non-zero levels and thresholds sets the values where level 2 and above begin; by default steps are equal up to the busiest day. color picks a palette slot from 1 to 8, and cellSize overrides the 11 to 18 px fit-to-width size.

### Frequently asked questions

#### What data does a React candlestick chart need?

An array of candles ordered oldest first, each with date (a Date, ISO string or timestamp), open, high, low and close, and an optional volume. Candles with a missing price are skipped. The volume strip appears when any candle has a volume, or when you set volume.

#### Does color carry the up or down signal alone?

No. Rising candles are hollow and falling ones are filled, and the readout names each move with an arrow, a sign and a percentage. Defaults for upColor and downColor hold at least 3:1 contrast on the chart surface in both themes, and you can override either palette slot.

#### Which keys work on the chart?

Tab focuses it, Left and Right read the previous and next candle, Home and End jump to the first and last, and Escape clears. With zoom on, plus and minus zoom, 0 resets, and Shift with Left or Right pans. Zoom is on by default and zoom={false} disables it.

#### How do I add a moving average?

Set average to a period count such as 20 and the chart overlays a simple moving average of the close over that many periods, drawn in after the candles. averageColor picks its palette slot, defaulting to 1. height and volumeHeight set the panel sizes.

### When to use the category bar chart

- Use it as a credit score bar to place a score, risk rating or health reading on a scale of named bands such as Poor, Fair, Good and Excellent, with the marker showing where the person sits now. ### Frequently asked questions

#### How do I make a category bar in React with a marker?

Pass data as bands whose values are widths on one scale, then marker with the number to point at and markerLabel such as Your score. The pin carries a glass bubble with the label and value, and its number rolls as the pin slides to a new value.

#### What if the marker is outside the scale?

A value past either end keeps its real number in the bubble, the announcement and the table, while the pin waits at that end with an arrow. That way an out-of-range reading is never silently clamped to look like an in-range one.

#### How can keyboard and screen reader users read the bands?

Tab focuses the bar, then the arrow keys move between bands (mirrored in right-to-left), Home and End jump to the ends, and Escape clears. Every band and the marker are in the chart's description, so nothing depends on color alone. aria-label is required.

#### Can I change the thickness and the printed values?

size accepts sm for 6px, md for 8px (the default) or lg for 12px. showValues prints the boundary values under the bar, thinned so they never collide, and showLegend adds a color key with each band's name. Both are booleans, and showValues defaults to true.

#### How do I build a chord diagram in React?

#### What happens with more than eight groups?

The chart is designed for eight groups or fewer, and the rest fold into an Other group. Choose the groups you care about and let the long tail collapse, or use a Sankey chart when the flows run one way from sources to targets.

### Example 1 of 2: Weekly cohorts

Twelve weekly signup cohorts. Switch between percentages and user counts: one glint sweeps the new numbers in, and the colors stay on retention so cohorts of different sizes stay comparable. Tab into the grid and use the arrow keys; Ctrl+Home / Ctrl+End jump to the corners.

```tsx
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
import { CohortChart } from "@/components/sheenui/charts/cohort-chart";
import { type CohortRow } from "@/components/sheenui/charts/cohort-chart/parts";
import { CohortTable } from "@/components/sheenui/charts/cohort-chart/table";
import { NumberTicker } from "@/components/sheenui/number-ticker/number-ticker";
// Package build (after the first npm release, or a packed tarball): import { ChartCard, NumberTicker, CohortTable, CohortChart, type CohortRow } from "@sheenui/theme";

const cohorts: CohortRow[] = [
  { cohort: "Jan 5", size: 1284, values: [1284, 560, 399, 356, 300, 257 /* … */] },
  { cohort: "Jan 12", size: 1342, values: [1342, 570, 442, 356, 337 /* … */] },
  // … later cohorts have fewer periods: they haven't reached them yet
];

// Weighted week-4 retention of the cohorts that have reached week 4
const reached = cohorts.filter((row) => typeof row.values[4] === "number");
const week4 =
  reached.reduce((sum, row) => sum + (row.values[4] ?? 0), 0) /
  reached.reduce((sum, row) => sum + row.size, 0);

export function Example() {
  return (
    <ChartCard
      title="Weekly retention"
      aside={<NumberTicker value={week4} format={{ style: "percent", maximumFractionDigits: 1 }} />}
      table={<CohortTable data={cohorts} labels={{ period: (i) => `Week ${i}` }} />}
    >
      <CohortChart
        data={cohorts}
        aria-label="Weekly retention by signup cohort"
      />
    </ChartCard>
  );
}
```

### When to use the cohort retention chart

- Use it as a retention heatmap (a cohort analysis table) where each row is a signup month and each column is periods since signup, with the cell color showing the share of the cohort still active.
- Use it to judge whether a product change helped: the weighted-average row on top gives a baseline, and each cell tooltip compares its retention with that average.
- Show user counts as well as percentages with the built-in switch, since the color always follows retention and cohorts of different sizes stay comparable.
- Skip it when you track one population over time, where a Line chart of a single retention curve is clearer, or when the rows are not cohorts, where a Heatmap is the generic grid.
- Pair it with ChartCard for the title and export, a Select to change the cohort granularity, and onCellClick to open a user list for the clicked cell in a Drawer or Dialog.


### Frequently asked questions

#### What data shape does a React cohort retention chart expect?

data is one row per cohort, oldest first, each with a cohort name, a size and values: the users still active in each period, period 0 first, with null for periods not reached yet. Set valuesAre to ratios if you pass retention as 0 to 1 instead. periods defaults to the longest row, and the first period reads 100 percent.

#### Is the cohort table keyboard accessible?

It is a real ARIA grid. Tab lands on one cell, arrow keys move between cells, Home and End go along a row, and Ctrl+Home or Ctrl+End go to the corners. Enter or Space calls onCellClick, and screen readers hear the cohort and period with every cell.

#### Can I control whether it shows percent or users?

Yes. view and onViewChange control it, defaultView sets the starting choice (percent by default), and viewToggle hides the switch entirely. Switching views sweeps the new numbers in with one glint across the grid, or changes instantly under reduced motion.

#### How does it behave with many cohorts on a phone?

Wide or long tables scroll inside their own container, and the header row and cohort column stay put. maxHeight sets how tall the table gets before it scrolls. steps and domain let you bucket the color scale and fix its range, and color picks the hue.

- Use it as a bar and line chart when a volume and a rate belong on one chart, such as orders as bars with a conversion line, or daily signups as bars with their 7-day average as a line.

### Frequently asked questions

#### How do I mix bars and lines in a React combo chart?

Give data rows an index key such as month plus one number per series, then list series, each with type set to bar or line. Bars and lines share one y-axis, so the series must use the same unit. aria-label is required.

#### Does it support a secondary y-axis?

No, on purpose. For measures with different units set indexed, which re-bases every series to the same starting point so they share one honest axis. A series that starts negative is rebased on its absolute value, so up still means up. formatIndex formats the indexed axis.

#### How do I read values with the keyboard?

Tab focuses the chart, Left and Right move the reading one category, Home and End jump to the ends, and Escape clears. Each move announces every series' value for that category. ComboTable offers the same data as a real table.

#### What does reduced motion change?

Marks normally draw in the first time the chart appears and tween when data changes. With reduced motion both become instant. Only the tooltip uses backdrop blur. height sets the chart height in px, defaulting to 280.
