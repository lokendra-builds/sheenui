## React Slide-Over Panel for Edit & Detail Views

URL: https://lokendra-builds.github.io/sheenui/overlays/side-drawer
Sidebar name: Side drawer

A glass React slide-over panel (side drawer) to view and edit records without leaving the page: validated form, unsaved-change guard, tabs, next/previous.

What it is: A glass React slide-over panel, or side drawer, that slides in to edit a record or show its details, with an edit form that guards unsaved changes.

Install:

```bash
npx shadcn@latest add https://lokendra-builds.github.io/sheenui/r/side-drawer.json
```

### Example 1 of 5: Edit form

Save with an empty name to see inline errors, the announced summary and focus jumping to the first problem. Edit something, then press Escape, the scrim or × (or swipe it away on a phone): you are asked before your changes are thrown away. ⌘↵ / Ctrl+Enter saves.

```tsx
import { useState } from "react";
import { Avatar } from "@/components/sheenui/avatar/avatar";
import { Button } from "@/components/sheenui/button/button";
import { Input } from "@/components/sheenui/input/input";
import { Select } from "@/components/sheenui/select/select";
import { SideDrawerContent } from "@/components/sheenui/side-drawer/parts/content";
import { SideDrawerHeader } from "@/components/sheenui/side-drawer/parts/header";
import { SideDrawer, SideDrawerTrigger } from "@/components/sheenui/side-drawer/side-drawer";
import { SideDrawerForm } from "@/components/sheenui/side-drawer/side-drawer-form";
import { Switch } from "@/components/sheenui/switch/switch";
import { Textarea } from "@/components/sheenui/textarea/textarea";
// Package build (after the first npm release, or a packed tarball): import { Avatar, Button, Input, Select, SideDrawer, SideDrawerContent, SideDrawerForm, SideDrawerHeader, SideDrawerTrigger, Switch, Textarea } from "@sheenui/theme";
import { Pencil as PencilIcon } from "lucide-react";

const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

const roles = [
  { value: "viewer", label: "Viewer" },
  { value: "editor", label: "Editor" },
  { value: "admin", label: "Admin" },
];

const initialProfile = { name: "Ada Lovelace", email: "ada@example.com", role: "editor", bio: "", notifications: true };

// Your API client.
declare const api: { saveProfile(values: typeof initialProfile): Promise<{ emailTaken?: boolean }> };

export function Example() {
  const [profile, setProfile] = useState(initialProfile);

  return (
    <SideDrawer>
      <SideDrawerTrigger render={<Button leading={<PencilIcon />} />}>Edit profile</SideDrawerTrigger>
      <SideDrawerContent size="md">
        <SideDrawerHeader
          leading={<Avatar name={profile.name} />}
          title="Edit profile"
          description="Your name and photo are visible to everyone in Acme."
        />
        <SideDrawerForm
          initialValues={profile}
          validate={(v) => ({
            name: v.name.trim() ? undefined : "Enter your full name",
            email: EMAIL.test(v.email.trim()) ? undefined : "Enter an email address like name@example.com",
          })}
          onSubmit={async (values) => {
            const res = await api.saveProfile(values);
            if (res.emailTaken) return { errors: { email: "That email is already used by another account" } };
            setProfile(values);
          }}
          successToast="Profile saved"
          successSeal
        >
          {(form) => (
            <>
              <Input label="Full name" autoComplete="name" {...form.field("name")} />
              <Input label="Email" type="email" autoComplete="email" {...form.field("email")} />
              <Select label="Role" name="role" items={roles} value={form.values.role}
                onValueChange={(value) => form.setValue("role", value ?? "viewer")} />
              <Textarea label="Bio" maxLength={160} {...form.field("bio")} />
              <Switch label="Email notifications" checked={form.values.notifications}
                onCheckedChange={(on) => form.setValue("notifications", on)} />
            </>
          )}
        </SideDrawerForm>
      </SideDrawerContent>
    </SideDrawer>
  );
}
```

### Example 2 of 5: Detail view, edit in place

Header with avatar, status and a copyable id; tabs for Overview, Activity and Notes. Edit swaps the details for a form in the same drawer, and Save or Cancel slides you back. Saving, Duplicate and Archive keep the drawer open, so they confirm in place (a check next to the title, announced) instead of a toast over the header. A half-written note also asks before the drawer closes.

```tsx
const statuses = [

const initialOrder = {
  id: "ord_8f21",
```

### Example 3 of 5: From a data table

Open a customer from their name (or the row menu: View details / Edit). Walk the rows in the table’s current sort and search order with the arrows in the footer or J / K; a half-written note stays with its customer, and closing asks before dropping it. Each record loads for a moment (skeleton); the 7th fails once to show the error state. Closing returns focus to the row you ended on.

```tsx
import { useState } from "react";
import { Avatar } from "@/components/sheenui/avatar/avatar";
import { Badge } from "@/components/sheenui/badge/badge";
import { UserCell } from "@/components/sheenui/data-table/cells";
import { DataTable } from "@/components/sheenui/data-table/data-table";
import { type DataTableColumn } from "@/components/sheenui/data-table/types";
import { SideDrawerContent } from "@/components/sheenui/side-drawer/parts/content";
import { SideDrawer } from "@/components/sheenui/side-drawer/side-drawer";
import { SideDrawerDetail, type SideDrawerDetailMode } from "@/components/sheenui/side-drawer/side-drawer-detail";
// Package build (after the first npm release, or a packed tarball): import { Avatar, Badge, DataTable, SideDrawer, SideDrawerContent, SideDrawerDetail, UserCell, type DataTableColumn, type SideDrawerDetailMode } from "@sheenui/theme";

type Customer = { id: string; name: string; email: string };

const asha: Customer = { id: "c1", name: "Asha Verma", email: "asha@example.com" };
const customers: Customer[] = [
  asha,
  { id: "c2", name: "Ravi Kumar", email: "ravi@example.com" },
  { id: "c3", name: "Meera Iyer", email: "meera@example.com" },
];

export function Example() {
  const [openId, setOpenId] = useState<string | null>(null);
  const [mode, setMode] = useState<SideDrawerDetailMode>("view");
  const index = customers.findIndex((c) => c.id === openId);
  const current = customers[index] ?? asha;

  const openRecord = (id: string, next: SideDrawerDetailMode = "view") => {
    setOpenId(id);
    setMode(next);
  };
  const rowButton = (id: string | null) =>
    id ? document.querySelector<HTMLElement>(`[data-customer-id="${CSS.escape(id)}"]`) : null;

  const columns: DataTableColumn<Customer>[] = [
    {
      id: "name",
      header: "Customer",
      // The name opens the record (click or Enter).
      cell: ({ row, highlight }) => (
        <button type="button" aria-haspopup="dialog" data-customer-id={row.id} onClick={() => openRecord(row.id)}>
          <UserCell name={row.name} email={row.email} highlight={highlight} />
        </button>
      ),
    },
  ];

  return (
    <>
      <DataTable
        caption="Customers"
        data={customers}
        columns={columns}
        rowActions={[
          { label: "View details", onSelect: (row) => openRecord(row.id) },
          { label: "Edit", onSelect: (row) => openRecord(row.id, "edit") },

      <SideDrawer open={openId !== null} onOpenChange={(next) => !next && setOpenId(null)}>
        {/* Back to the row shown last (after J / K), not the one first opened. */}
        <SideDrawerContent size="lg" resizable storageKey="customers" finalFocus={() => rowButton(openId) ?? true}>
          <SideDrawerDetail
            recordKey={current.id}
            avatar={<Avatar name={current.name} />}
            title={current.name}
            status={<Badge tone="success" dot>Active</Badge>}
            subtitle={current.email}
            recordId={current.id}
            recordIdLabel="Customer ID"
            navigation={{
              index,
              count: customers.length,
              onIndexChange: (i) => setOpenId(customers[i]?.id ?? openId),
              labels: { previous: "Previous customer", next: "Next customer" },
            }}
            mode={mode}
            onModeChange={setMode}
            tabs={[{ value: "overview", label: "Overview", content: <p>Plan, usage and billing go here.</p> }]}
            editor={<p>A SideDrawerForm goes here.</p>}
```

### Example 5 of 5: Inspector (non-modal)

modal={false}: no scrim and no focus trap, so the list stays usable while the panel is open. Clicking another file updates it; clicking the shown file again clears the selection (the empty state). Escape closes it while focus is inside it, and focus goes back to the file shown.

```tsx
import { useState } from "react";
import { DescriptionItem, DescriptionList } from "@/components/sheenui/description-list/description-list";
import { SideDrawerContent } from "@/components/sheenui/side-drawer/parts/content";
import { SideDrawer } from "@/components/sheenui/side-drawer/side-drawer";
import { SideDrawerDetail } from "@/components/sheenui/side-drawer/side-drawer-detail";
// Package build (after the first npm release, or a packed tarball): import { DescriptionItem, DescriptionList, SideDrawer, SideDrawerContent, SideDrawerDetail } from "@sheenui/theme";
import { File as FileIcon } from "lucide-react";

const files = [
  { id: "f1", name: "roadmap.pdf", kind: "PDF", path: "/Docs/roadmap.pdf", owner: "Asha" },
  { id: "f2", name: "logo.svg", kind: "Image", path: "/Brand/logo.svg", owner: "Ravi" },
];

export function Example() {
  const [selected, setSelected] = useState<string | null>("f1");
  const [open, setOpen] = useState(true);
  const fileButtons = new Map<string, HTMLElement>(); // filled by the file list (ref callbacks)
  const index = files.findIndex((f) => f.id === selected);
  const file = files[index]; // undefined: nothing selected

  return (
    <SideDrawer open={open} onOpenChange={setOpen} modal={false}>
      {/* Escape / × give focus back to the file shown now, not the one that opened the panel. */}
      <SideDrawerContent size="sm" inset finalFocus={() => (selected && fileButtons.get(selected)) || true}>
        <SideDrawerDetail
          recordKey={file?.id ?? "none"}
          avatar={file && <FileIcon />}
          title={file ? file.name : "Details"}
          subtitle={file?.kind}
          empty={!file}
          labels={{ emptyTitle: "No file selected", emptyDescription: "Pick a file in the list to see its details here." }}
          navigation={
            file && {
              index,
              count: files.length,
              onIndexChange: (i) => setSelected(files[i]?.id ?? null),
              labels: { previous: "Previous file", next: "Next file" },
            }
          }
        >
          {file && (
            <DescriptionList layout="stacked" size="sm">
              <DescriptionItem label="Location" copyValue={file.path}>{file.path}</DescriptionItem>
              <DescriptionItem label="Owner">{file.owner}</DescriptionItem>
            </DescriptionList>
          )}
        </SideDrawerDetail>
      </SideDrawerContent>
    </SideDrawer>
  );
}
```

### Keyboard

| Keys | Action |
| --- | --- |
| Esc | Close (asks first when a form has unsaved changes). Inspector: only while focus is inside it. |
| Ctrl + Enter / ⌘ + Enter | Save the form from any field. |
| J / K | Next / previous record (not while typing in a field). |
| ← / → / Home / End | On the resize handle: wider / narrower (Shift for bigger steps), min / max. |
| Tab | Moves through the panel; focus stays inside a modal drawer and returns to what opened it. |

### Accessibility

- role="dialog", named by the header title and described by its description. A modal drawer makes the page behind inert and traps focus; modal={false} (an inspector) does neither, and Escape then works only while focus is inside it.
- On open, focus goes to the element marked data-autofocus, else the first field of a SideDrawerForm (never on touch screens), else the panel itself so screen readers read its title. On close it returns to the opener (or finalFocus).
- The resize handle is a labeled separator with aria-valuenow, and works with the arrow keys, Home / End and a double-click; Escape cancels a drag. It is hidden under 640 px, where the panel is full width.
- notify() writes into a polite live region inside the panel, so "Saved" is announced even from a modal drawer. A close guard that keeps the drawer open leaves focus where it is: show your own confirmation so people know why.
- Under reduced motion the panel fades in place instead of sliding.

### When to use the side drawer

- Use it as a slide-over panel for an order or issue detail peek in a table, where clicking a row slides a panel in from the right and the list stays visible behind it, with previous and next navigation.
- Use it for editing a record, such as a user profile, with the validated SideDrawerForm, an inline error summary and a close guard asking Discard unsaved changes before Escape or the scrim closes it.
- Use modal={false} for an inspector panel that leaves the page usable: there is no scrim or focus trap, and outside clicks do not close it.
- Skip it when you need a bottom sheet for phones or a plain navigation menu, which Drawer covers, and use Dialog for a small centered prompt rather than a record panel.
- Pair it with DescriptionList and Tabs for detail bodies, DataTable for the list that opens it, and AlertDialog or the notify function when saving needs confirmation feedback.


### Frequently asked questions

#### How do I build a slide-over panel in React for editing a record?

Compose SideDrawer with SideDrawerTrigger, SideDrawerContent, SideDrawerHeader, SideDrawerBody and SideDrawerFooter, or use SideDrawerForm or SideDrawerDetail for the two common bodies. It slides in from the inline end, right in left-to-right pages and left in right-to-left ones.

#### How do close guards work?

useSideDrawerCloseGuard registers a function returning a boolean or a promise. Every way of closing, the x button, Escape, the scrim, a swipe or a Cancel button, asks it first. Typical use is a Discard unsaved changes prompt; requestClose runs the guards from code.

#### Can users resize the panel?

Yes. Set resizable on SideDrawerContent for a handle on the free edge. Drag it, or focus it and use Left and Right, with Shift for bigger steps, and Home and End for min and max. Double-click resets, and storageKey remembers the width in localStorage. It is hidden under 640px.

#### How do I show feedback like Saved without a toast?

Call useSideDrawer().notify("Saved", { announce: "..." }). A check pops in beside the header title, and the announce text is read politely by screen readers. A corner toast would cover the header, so this suits actions that keep the panel open.
