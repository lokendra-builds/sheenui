## About effects

### Overview

These are the animated React components in SheenUI: glassy, classy effects you drop onto a page to make it feel alive. Each of the 19 pages below has a live demo, the props, the keyboard and reduced-motion behavior, and the files to copy. They are built with Motion (formerly Framer Motion), the same engine that powers the rest of the library, so one provider sets the spring and the pace for everything.

The set mixes surface effects and text effects. [Liquid Glass for React](https://lokendra-builds.github.io/sheenui/effects/liquid-glass) bends the background behind a panel, the way iOS 26 does, with a frosted fallback for Safari and Firefox. A [border beam](https://lokendra-builds.github.io/sheenui/effects/border-beam) sends light around a card, a [spotlight card](https://lokendra-builds.github.io/sheenui/effects/spotlight-card) follows the pointer, and the [macOS-style dock](https://lokendra-builds.github.io/sheenui/effects/macos-dock) magnifies icons as you move across them. For text there are a [number ticker](https://lokendra-builds.github.io/sheenui/effects/number-ticker), a [typewriter](https://lokendra-builds.github.io/sheenui/effects/typewriter), [shimmer text](https://lokendra-builds.github.io/sheenui/effects/shimmer-text) and a [blur-in](https://lokendra-builds.github.io/sheenui/effects/blur-in) reveal.

Which effect for which job: for text, [typewriter](https://lokendra-builds.github.io/sheenui/effects/typewriter), [word rotate](https://lokendra-builds.github.io/sheenui/effects/word-rotate), [shimmer text](https://lokendra-builds.github.io/sheenui/effects/shimmer-text) and [text reveal](https://lokendra-builds.github.io/sheenui/effects/text-reveal); for a background, [particles](https://lokendra-builds.github.io/sheenui/effects/particles) and [meteors](https://lokendra-builds.github.io/sheenui/effects/meteors); for a card, [3D tilt](https://lokendra-builds.github.io/sheenui/effects/3d-tilt-card), [spotlight](https://lokendra-builds.github.io/sheenui/effects/spotlight-card) and [border beam](https://lokendra-builds.github.io/sheenui/effects/border-beam); for a diagram, [animated beam](https://lokendra-builds.github.io/sheenui/effects/animated-beam) and [orbiting circles](https://lokendra-builds.github.io/sheenui/effects/orbiting-circles); for a success moment, [confetti](https://lokendra-builds.github.io/sheenui/effects/confetti).

By how they move: [particles](https://lokendra-builds.github.io/sheenui/effects/particles), [meteors](https://lokendra-builds.github.io/sheenui/effects/meteors), [marquee](https://lokendra-builds.github.io/sheenui/effects/marquee) and [orbiting circles](https://lokendra-builds.github.io/sheenui/effects/orbiting-circles) loop on their own; [spotlight](https://lokendra-builds.github.io/sheenui/effects/spotlight-card), [3D tilt](https://lokendra-builds.github.io/sheenui/effects/3d-tilt-card) and the [dock](https://lokendra-builds.github.io/sheenui/effects/macos-dock) answer the pointer; [scroll progress](https://lokendra-builds.github.io/sheenui/effects/scroll-progress) answers the page scroll; [confetti](https://lokendra-builds.github.io/sheenui/effects/confetti) and [morphing dialog](https://lokendra-builds.github.io/sheenui/effects/morphing-dialog) play once when you trigger them. Pick the least continuous motion that does the job, because a loop is the only kind that keeps running while someone reads.

What every effect shares. One SheenMotionProvider at the root of your app wraps Motion’s config: it makes Motion follow the operating system’s reduced-motion setting and SheenUI’s own switch, sets the default spring, pauses looping CSS animations while they are off screen and pauses decorative loops in a hidden tab. Timing comes from shared tokens, with durations between 0.1 and 0.6 seconds, an exit that is always shorter than the entrance and never overshoots, so a toast and a dialog feel like one product.

To use one, open its page and copy the files it lists, which include the motion tokens that effect imports, or install it through the shadcn registry as the [installation page](https://lokendra-builds.github.io/sheenui/docs/installation) shows, after the [Tailwind CSS v4 setup](https://lokendra-builds.github.io/sheenui/docs/tailwind-v4). The effects are plain React source in your repository, so you can change a spring or a duration without waiting for a release.

Motion that ignores people is a bug, so every effect respects reduced motion and pauses when it leaves the screen. Learn the patterns in [12 Framer Motion examples](https://lokendra-builds.github.io/sheenui/guides/framer-motion-examples), or read why the package was renamed in [Framer Motion is now Motion](https://lokendra-builds.github.io/sheenui/guides/framer-motion-to-motion). For the static building blocks see [all glass UI components](https://lokendra-builds.github.io/sheenui/components/), and for full screens the [React blocks](https://lokendra-builds.github.io/sheenui/blocks/).

### Frequently asked questions

### Which animation library do the effects use?

Motion, the library formerly called Framer Motion, imported from motion/react. Springs and durations come from shared motion tokens so every effect feels the same.

### What happens with reduced motion?

Each effect has a still fallback: movement turns into a short fade or the final state is shown at once, whether the setting comes from the operating system or from SheenUI's own toggle.

### Can I use one effect without the rest of SheenUI?

Yes. Each effect page lists the files to copy; they need Motion (motion/react), Tailwind CSS v4 and the SheenUI tokens and motion presets they import. Add SheenMotionProvider at the root as well: without it Motion ignores the operating system's reduced-motion setting.

### Do the effects hurt performance?

They animate transform and opacity, pause when off screen or in a hidden tab, and a page keeps to a budget of 8 blurred surfaces in view. See the backdrop-filter performance guide for the glass cost.
