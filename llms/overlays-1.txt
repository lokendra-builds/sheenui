## React Alert Dialog for Confirmations

URL: https://lokendra-builds.github.io/sheenui/overlays/alert-dialog
Sidebar name: Alert dialog

A glass React alert dialog for actions that matter: it focuses the safe choice, shows a spinner while it runs and keeps errors visible. Base UI.

What it is: A glass React alert dialog that asks before destructive actions, focuses the safe choice first and stays open with the error if the action fails.

### Example 1 of 4: Destructive confirmation

onConfirm returns a promise: the action shows a spinner, Cancel and Escape wait, and the dialog closes when it resolves. Turn on the failure to see the inline error.

```tsx
import { ConfirmDialog } from "@/components/sheenui/alert-dialog/alert-dialog";
import { Button } from "@/components/sheenui/button/button";
import { useToast } from "@/components/sheenui/toast/toast";
// Package build (after the first npm release, or a packed tarball): import { Button, ConfirmDialog, useToast } from "@sheenui/theme";

// Your API client.
declare const api: { deleteProject(id: string): Promise<void> };

export function Example() {
  const toast = useToast();

  return (
    <ConfirmDialog
      trigger={<Button variant="danger">Delete project</Button>}
      title="Delete “Aurora”?"
      description="The project, its 24 deployments and every environment variable are removed for the whole team. This can’t be undone."
      confirmLabel="Delete project"
      labels={{ pending: "Deleting…" }}
      onConfirm={async () => {
        await api.deleteProject("aurora"); // throw to keep the dialog open with the message
        toast.success("Project deleted");
      }}
    />
  );
}
```

### Example 3 of 4: useConfirm()

Ask from any event handler and await the answer: true once the action has finished, false if dismissed. One dialog serves the whole list. After a key is revoked, focus moves to the next row's Revoke button (or to Restore once the list is empty), never to the page; pass finalFocus to choose another target.

```tsx
import { useState } from "react";
import { useConfirm } from "@/components/sheenui/alert-dialog/alert-dialog";
// Package build (after the first npm release, or a packed tarball): import { useConfirm } from "@sheenui/theme";

type ApiKey = { id: string; name: string; hint: string };

// Your API client.
declare const api: { revoke(id: string): Promise<void> };

export function Example() {
  const [confirm, confirmDialog] = useConfirm();
  const [keys, setKeys] = useState<ApiKey[]>([{ id: "k1", name: "CI deploy", hint: "sk_live_…a41f" }]);

  async function revoke(key: ApiKey) {
    const ok = await confirm({
      tone: "warning",
      title: `Revoke “${key.name}”?`,
      description: `Apps using ${key.hint} stop working immediately.`,
      confirmLabel: "Revoke key",
      onConfirm: () => api.revoke(key.id),
      // Optional: focus goes to the same spot in the list by default once the row is removed.
      // finalFocus: newKeyButtonRef,
    });
    if (ok) setKeys((list) => list.filter((k) => k.id !== key.id));
  }

  return (
    <>
      {keys.map((key) => (
        <button key={key.id} type="button" onClick={() => revoke(key)}>
          Revoke {key.name}
        </button>
      ))}
      {confirmDialog}
    </>
  );
}
```

### Accessibility

- role="alertdialog" named by the title and described by the description; the page behind is inert.
- Initial focus lands on Cancel for danger and warning tones (the safe choice), on the action for info, or on the type-to-confirm field.
- While pending, aria-busy and a polite status announce it; errors use role="alert". The tone icon is decorative, so the title carries the meaning.
- If the trigger was removed (a deleted row), focus lands on the same spot in the list.

### When to use the alert dialog

- Use it as a delete confirmation modal before deleting a project, revoking an API key or discarding unsaved changes, where the person must choose because an outside click will not dismiss it, only nudge the panel.
- Use ConfirmDialog when you want the whole thing prebuilt: icon, title, description, Cancel and action, a loading state while an async onConfirm runs, and inline errors if it throws.
- Use useConfirm in an event handler when awaiting the answer reads best, as in if (await confirm({ title: "Delete?" })), or add type-to-confirm for actions as serious as deleting an organization.
- Skip it when the content is informational or a form that people may dismiss freely; Dialog closes on an outside press, and Toast fits a quiet notice better than a blocking prompt.
- Pair it with Button for the trigger through the render prop, Toast to confirm that the action happened, and DataTable rows, where ConfirmDialog and useConfirm move focus to the matching control in the neighboring row after a delete.


### Frequently asked questions

#### What is the difference between an alert dialog and a dialog in React?

Alert dialogs use role="alertdialog" and do not close on an outside press; the panel nudges instead so the click is not silently ignored. A regular Dialog is dismissable. Focus is trapped, the page behind is inert, and Escape still closes it.

#### Where does focus go when the alert dialog opens?

For danger and warning tones, Cancel is focused first as the safe choice; for info, the action is. With type-to-confirm, the text field gets focus. Focus returns to the trigger on close, and if confirming removes the trigger, ConfirmDialog and useConfirm move it to the matching control in the row that takes its place, or the row before.

#### How do I handle async work in the confirm button?

Return a promise from onConfirm on ConfirmDialog. The action button shows a loading state, the dialog stays open while it runs, and a thrown error appears inline with a shake. On the composable parts, set the action's close behavior off and use its loading prop yourself.

#### Can I open one alert dialog from several triggers?

Yes. Create a handle with createAlertDialogHandle and pass it to AlertDialog and to triggers rendered elsewhere. The tone prop is danger, warning or info. It is built on Base UI AlertDialog; under reduced motion the popup only fades, with no spring.

### SheenUI Command Palette or cmdk?

cmdk is a popular unstyled command menu for React that you compose and style yourself. SheenUI's CommandPalette is styled glass and ships the behaviors most apps then build: groups, nested pages, fuzzy search with highlighted matches, recent commands and a Cmd or Ctrl+K shortcut. Pick cmdk when you want full control of the markup and styling; pick this one when you want those behaviors ready to use and the source to copy.


### Frequently asked questions

#### How do I add a Cmd+K command palette to a React app?

Render CommandPalette with an items array of objects that have id and label, and optionally group, icon, keywords, shortcut and onSelect. The shortcut prop defaults to mod+k, which is Cmd on Apple and Ctrl elsewhere; pass shortcut={false} to register none. A trigger element adds a button that opens it.

#### Which keys work inside the palette?

Up and Down, or Ctrl+N and Ctrl+P, move through results; Enter runs the command; Escape closes it or goes back from a nested page; Page Up and Down jump. Backspace in an empty field also goes back. Focus stays in the field via aria-activedescendant.

#### How do recent commands and shortcuts work?

Used commands are listed first under Recent. They are kept in memory, in localStorage with recentStorageKey, or controlled with recent and onRecentChange; maxRecent defaults to 5 and 0 turns it off. A shortcut on an item is displayed only, so you must bind the key yourself.

#### Will it stay fast with thousands of commands?

Results while searching are limited by maxResults, which defaults to 100, so only the best matches are listed. The result count is announced politely, and the highlight glides between rows. With reduced motion the pages fade instead of sliding sideways.

```tsx
// onOpenChange gets the event that opened the menu: a MouseEvent for a right-click or

        </MenuSub>

        <MenuCheckboxItem checked={snap} onCheckedChange={setSnap}>Snap to grid</MenuCheckboxItem>
        <MenuRadioGroup value={zoom} onValueChange={(value) => setZoom(value as string)}>
          <MenuLabel>Zoom</MenuLabel>
```

### Example 2 of 4: Snap points

Peek, half and full heights. Peek is measured from the content (handle, header and the first row) and half always shows more than peek, even on a landscape phone. Drag between them, flick to skip one, or use the handle: it is a button that reads out the current height (Enter cycles, arrow keys step). Keyboard focus is never hidden: rows scroll into view inside the sheet, and a control that can't (below the screen edge) opens it fully. A click or tap never changes the height.

```tsx
import { useState } from "react";
import { Button } from "@/components/sheenui/button/button";
import { Drawer, DrawerTrigger } from "@/components/sheenui/drawer/drawer";

const places = [{ name: "Café Aurora" }, { name: "Riverside Park" }, { name: "Night Market" }];

export function Example() {
  // "peek" = handle + header + first row (measured); "half" = 50% of the screen, at least a row above peek.
```

### When to use the Drawer / Sheet

- Use it for a mobile bottom sheet that people drag between a peek, half and full height, such as filters on a product list or a place card on a map, or as a side panel on desktop.
- Use it for a navigation menu or cart panel sliding in from the left or right with side="left" or "right", or floating off the edge with the inset prop on DrawerContent.
- Use it for a quick form on a phone, where keyboardAware (on by default) keeps focused fields above the on-screen keyboard while the sheet remains swipeable.
- Skip it when you need a centered modal, which Dialog handles, or a record detail and edit panel with close guards and resizing, where SideDrawer is built for that.
- Pair it with Button through the render prop on DrawerTrigger, Tabs or RadioGroup inside DrawerBody for filter controls, and Toast to report that the applied choices were saved.


### Frequently asked questions

#### How do I build a bottom sheet in React with snap points?

Pass snapPoints such as ["peek", "half", "full"] to Drawer, or your own heights as fractions of the viewport, pixel numbers or strings like 18rem. Control it with snapPoint and onSnapPointChange. The peek height is measured from the handle, header and first body row.

#### How do I use the drag handle with a keyboard?

With snap points, the handle is a real button: click or Enter cycles them, ArrowUp and ArrowDown step through them, and it tells screen readers the current height. Escape closes the drawer. The popup is role="dialog" named by DrawerTitle, and the page behind is inert.

#### Which sides and modes does Drawer support?

side can be bottom (the default), top, left or right, plus start and end, which follow the text direction. Snap points apply to bottom sheets only. modal defaults to true, which traps focus and locks scroll. Safe-area insets are padded wherever the panel touches a screen edge, so notches and home indicators do not cover content. It is built on Base UI Drawer.

#### What does reduced motion change?

With reduced motion, from the OS or the data-motion reduced attribute, the panel fades in place instead of sliding. Dragging still follows the finger, because that is direct manipulation. Reduced transparency and forced colors give the glass-3 panel a solid surface.

### When to use the dropdown menu

- Use it as an animated dropdown menu for a row actions button in a table, where a three-dot trigger opens Edit, Duplicate and Delete, with tone="danger" marking the destructive item.
- Use it for an account menu in a navbar, with a MenuHeader for the signed-in user, MenuLinkItem entries for Settings and Billing, and a MenuSub for a theme or language choice.
- Use it for view options with MenuCheckboxItem and MenuRadioGroup, such as showing or hiding columns and choosing a sort order, with the chosen state kept in your own React state.
- Skip it when the user is choosing a value for a form field; Select is built for that, and an application menu bar with File, Edit and View belongs in Menubar.
- Pair it with Button via render on MenuTrigger, KbdShortcut or the shortcut prop to show key hints, and AlertDialog to confirm items that cannot be undone.


### Frequently asked questions

#### How do I build a dropdown menu in React with submenus?

Compose Menu, MenuTrigger and MenuContent, then add MenuItem rows. Wrap a MenuSubTrigger and its MenuSubContent in MenuSub for a submenu. Right Arrow, or Left in right-to-left, opens it; Left Arrow or Escape closes it. It is built on Base UI Menu.

#### Which keys does the menu respond to?

Enter, Space or Down on the trigger opens it, and Up opens with the last item highlighted. Up and Down move, Home and End jump, typing jumps to a matching item, and Enter or Space activates. Escape closes the menu and returns focus to the trigger.

#### Does the shortcut prop bind the key?

No. The shortcut on a MenuItem shows a platform-aware key combination and sets aria-keyshortcuts, but it does not bind the key; handle it yourself with your own listener. Use icon, description, trailing and inset to shape each row, and onClick for the action.

#### How do I keep the menu open after choosing an item?

The menu closes after an item's onClick by default. Set closeOnClick={false} on that item to keep it open, which suits checkbox items. Disabled items stay in the arrow-key order but cannot be activated. Reduced motion makes the popup fade and the highlight jump.

### When to use the hover card

- Use it as a profile preview popover for @mentions in a comment thread, where hovering a username link shows a profile preview with avatar, bio, stats and join date after a short delay.
- Use it for external links in documentation, with LinkPreview content showing the site, title, description and a 1.91 to 1 image so readers can judge a link before leaving.
- Use it for a link in a table or feed where passing the pointer across should do nothing: the default delay is 500 milliseconds, with a closeDelay of 250, so quick passes stay quiet.
- Skip it when the content is interactive or essential; the card is not reachable by Tab, so Popover fits buttons and forms, and Tooltip fits a short label for an icon.
- Pair it with Avatar and Badge inside ProfilePreview, Link-styled triggers using variant="link", and the page the link opens, where the essential version of the information should live.


### Frequently asked questions

#### How do I make a React hover card for a link preview?

Use HoverCard with a HoverCardTrigger, which renders an a element, so pass href, and HoverCardContent holding ProfilePreview or LinkPreview. Place it with side, align and sideOffset. Use padded={false} for edge-to-edge content like a preview image.

#### Can keyboard and screen reader users reach the hover card?

Focusing the link opens the card after the delay and Escape closes it, but the card content is not reachable by Tab or read by screen readers. Base UI keeps the link as the one accessible element, so keep essential information on the destination page and avoid buttons inside.

#### What happens on touch screens, where there is no hover?

The first tap on the trigger opens the card and a second tap follows the link; a tap outside closes it. The touchHint prop on HoverCardContent sets the line shown after the first tap, and null hides it, for example when the trigger is not a link. Plain triggers get a 44px tap area.

#### How do I change the delay or style the trigger?

Set delay (default 500) and closeDelay (default 250) in milliseconds on HoverCardTrigger. variant="link" gives accent underlined text for links in a sentence, and "plain" leaves only the focus ring, suiting avatars and chips. Reduced motion makes the card fade only.

### Example 2 of 2: Every platform

Chips for hints in text; inline for menus (⇧⌘P on a Mac, Ctrl+Shift+P elsewhere), in each platform's own modifier order. Pin a platform to document both.

```tsx
import { useEffect } from "react";
import { KbdShortcut } from "@/components/sheenui/kbd/kbd";
import { formatShortcut, matchesShortcut } from "@/components/sheenui/kbd/shortcut";
// Package build (after the first npm release, or a packed tarball): import { KbdShortcut, formatShortcut, matchesShortcut } from "@sheenui/theme";

export function Example() {
  // Helpers
  const parts = formatShortcut("shift+mod+p", "other"); // { keys: ["Ctrl", "Shift", "P"], spoken: "Control Shift P", aria: "Control+Shift+P" }

  useEffect(() => {
    const onKeyDown = (event: KeyboardEvent) => {
      if (matchesShortcut(event, "mod+k")) console.log("palette"); // in a keydown handler
    };
    window.addEventListener("keydown", onKeyDown);
    return () => window.removeEventListener("keydown", onKeyDown);
  }, []);

  return (
    <>
      <p>{parts.spoken}</p>
      <KbdShortcut keys="shift+mod+p" /> {/* chips */}
      <KbdShortcut keys="shift+mod+p" variant="inline" /> {/* menu text */}
      <KbdShortcut keys="shift+mod+p" platform="mac" /> {/* always ⇧ ⌘ P */}
    </>
  );
}
```

- Pass platform to force Mac or other symbols; by default the visitor's platform decides, so "mod" shows Cmd on a Mac and Ctrl elsewhere.

### When to use the Kbd component

- Use it as a keyboard shortcut component in help text and docs to show a single key, such as pressing Esc to close a panel, as a native kbd element with a sm or md size.
- Use KbdShortcut next to a search button or a menu item to show a combination like mod+k, which reads as the Command symbol and K on a Mac and Ctrl K elsewhere.
- Use it inside an onboarding checklist or a shortcuts cheat sheet, where variant="inline" writes plain text like Ctrl+Shift+P and the chips variant draws one cap per key.
- Skip it when the element is clickable or needs behavior; Kbd is a label and not a control, so Button fits an action, and binding the key still needs your own handler.
- Pair it with Dropdown menu or Command palette items, which already show shortcuts, Tooltip to reveal a key when hovering an icon button, and the useShortcutPlatform hook for custom text.


### Frequently asked questions

#### How do I show a keyboard shortcut in React?

Use KbdShortcut with keys as a string like shift+mod+p or an array. The word mod means Command on Apple platforms and Ctrl elsewhere. It only displays the shortcut; binding the key is up to you, for example with matchesShortcut or the useCommandShortcut hook.

#### Does it cause hydration mismatches for Mac and Windows?

useShortcutPlatform reads the browser once and returns other during server rendering, so the server and client agree on the first render. Pass platform="mac" or "other" to force one, which is useful for docs that show both platforms side by side.

#### How do screen readers read the key caps?

The visible keys are aria-hidden and a visually hidden span reads the key names, such as Command K, instead of symbols. Set announce={false} when a parent already exposes it, for instance a menu item with aria-keyshortcuts. Single Kbd text is read as written.

#### Can I rename keys for another language?

Yes. KbdShortcut takes a labels prop that overrides key names for i18n, and defaultKbdLabels holds the default glyphs and spoken names per platform. The key caps are flat with no backdrop blur and no motion, and forced colors draw a CanvasText border.

### When to use Menubar

- Use it as a desktop-style app menu bar for a web-based editor or admin tool with File, Edit and View menus along the top, where many commands are grouped the way a desktop application groups them.
- Use it when hovering a neighboring trigger should switch the open menu, as in desktop apps, and the accent tint should glide from one trigger to the next.
- Use it on narrow screens, where the bar scrolls sideways instead of wrapping to a second row, and set orientation="vertical" when you want the triggers stacked in a column.
- Skip it when you have one menu behind one button; Dropdown menu is simpler, and a site's top-level links with panels of content belong in a navigation menu instead.
- Pair it with MenuItem, MenuCheckboxItem and MenuSub for the contents, KbdShortcut for shown key combinations, and CommandPalette so rarely used commands are searchable too.


### Frequently asked questions

#### How do I build a File Edit View menu bar in React?

Compose Menubar with a MenubarMenu for each menu, each holding a MenubarTrigger and a MenubarContent. Inside the content, use the dropdown menu's parts such as MenuItem, MenuCheckboxItem and MenuSub. It is built on Base UI Menubar and passes its props through.

#### Which keys move between menus?

Tab reaches the bar once. Left and Right move between triggers and, while one menu is open, switch the open menu. Down, Enter or Space open one, and Escape closes it and returns focus to its trigger. Inside a menu, Right opens a submenu and Left closes it.

#### What ARIA roles does the menubar use?

The bar has role="menubar" and each trigger is a real button with aria-haspopup="menu" and aria-expanded. Menu popups are role="menu". Triggers are 44px tall on touch screens, and an inset focus ring ensures focus is never clipped by the scrolling bar.

#### How does the open-menu highlight animate?

The accent tint of the open menu glides between triggers using a shared layout animation. With reduced motion it jumps instead, and in forced colors it is hidden. The bar is a glass-2 surface, and the popup drops below the trigger with left edges aligned.
