### Example 1 of 3: Single date

The selected-day pill glides to the new day; months slide in the direction you travel. Click the caption for the month and year grids.

```tsx
import { useState } from "react";
import { Calendar } from "@/components/sheenui/calendar/calendar";
import { GlassCard } from "@/components/sheenui/glass-card/glass-card";
// Package build (after the first npm release, or a packed tarball): import { Calendar, GlassCard } from "@sheenui/theme";

const startOfDay = (d: Date) => new Date(d.getFullYear(), d.getMonth(), d.getDate());

export function Example() {
  const [date, setDate] = useState<Date | null>(startOfDay(new Date()));

  return (
    <GlassCard className="max-w-full rounded-sheen-xl p-2 sm:p-3">
      <Calendar value={date} onValueChange={setDate} aria-label="Pick a date" />
    </GlassCard>
  );
}
```

### Example 2 of 3: Range, two months, unavailable days

Pick a start, then hover (or arrow) to preview the range; a range can't cross a booked day (every 9th and 10th here). Past days are off limits. Each caption opens the month grid for its own panel.

```tsx
import { useState } from "react";
import { Calendar } from "@/components/sheenui/calendar/calendar";
import { type DateRange } from "@/components/sheenui/calendar/date-utils";
import { GlassCard } from "@/components/sheenui/glass-card/glass-card";
// Package build (after the first npm release, or a packed tarball): import { Calendar, GlassCard, type DateRange } from "@sheenui/theme";

export function Example() {
  const today = new Date();
  const [range, setRange] = useState<DateRange>({ start: null, end: null });

  const booked = (d: Date) => d.getDate() % 9 === 0 || d.getDate() % 10 === 0;

  return (
    <GlassCard className="max-w-full rounded-sheen-xl p-2 sm:p-4">
      <Calendar
        mode="range"
        numberOfMonths={2}
        min={today}
        isDateDisabled={booked}
        value={range}
        onValueChange={setRange}
        aria-label="Stay dates"
      />
    </GlassCard>
  );
}
```

### Example 3 of 3: Locales

Same component, different locale: week start, names and digits all change. Arabic also runs right to left (arrow keys follow).

```tsx
import { useState } from "react";
import { Calendar } from "@/components/sheenui/calendar/calendar";
// Package build (after the first npm release, or a packed tarball): import { Calendar } from "@sheenui/theme";

export function Example() {
  const today = new Date();
  const [locale, setLocale] = useState("ar-EG");
  const rtl = ["ar", "he", "fa"].includes(locale.split("-")[0] ?? locale);

  return (
    <div dir={rtl ? "rtl" : undefined} lang={locale}>
      <button onClick={() => setLocale(locale === "ar-EG" ? "de-DE" : "ar-EG")}>Switch language</button>
      <Calendar key={locale} locale={locale} defaultValue={today} aria-label="Localised calendar" />
    </div>
  );
}
```

### Accessibility

- A WAI-ARIA date grid: role="grid" per month, one day in the tab order (roving tabindex), each day named with its full date.
- Today, selected, range start and end, and unavailable days are all in the name. Unavailable days stay focusable but cannot be selected.
- A polite live region announces month changes. Selection never relies on color alone.

### When to use Calendar

- Use it as an accessible calendar for a booking page where the month grid stays on screen, such as picking a check-in and check-out range for a rental, with range mode previewing the span as the pointer or keyboard focus moves.
- Use it inside an admin scheduler or a reporting filter where people jump between months and years often, since the caption opens a month grid and then a year grid for long jumps.
- Use it for a localized product: week start, month names, weekday names and even digits come from Intl, so locale="ar-EG" or "en-GB" needs no extra configuration or translation files for the grid itself.
- Skip it when the calendar should hide behind a field in a compact form; DatePicker wraps the same grid in a popover on desktop and a bottom sheet on phones, so it fits better there.
- Pair it with Popover to build your own trigger, with Field and Label for naming the grid in a form, and with Badge or Button to show the chosen range and a clear action beside it.


### Frequently asked questions

#### How do I select a date range in a React calendar?

Pass mode="range" and read value or onValueChange as an object with start and end. While the person is picking, end is null until the second click. By default a range cannot cross an unavailable day; set allowUnavailableInRange to let it span booked or disabled days.

#### Which keys work inside the Calendar?

It follows the WAI-ARIA date grid: arrows move by day or week, Home and End go to the week's edges, Page Up and Page Down change the month, and Shift with them changes the year. Enter or Space selects. Only one day is in the tab order, and right-to-left flips Left and Right.

#### How do I block weekends or already booked days?

Give isDateDisabled a function that returns true for those dates, and use min and max for outer limits. Unavailable days stay focusable so keyboard users can still land on them, and they are named as unavailable for screen readers, but they can never be selected.

#### Why does my server-rendered Calendar cause a hydration mismatch?

Both locale and today default to the browser's values, which differ between server and client. Pass an explicit locale such as en-US and a fixed today date on prerendered pages, tests and screenshots, and the HTML will match what hydrates. The component is marked use client.

### Frequently asked questions

#### What format does the React color picker return?

The value is always emitted as hex, like #7c5cff, or an eight-digit hex such as #7c5cff80 when the opacity is below 100%. Any hex, rgb() or hsl() string is accepted as input. The format prop only changes which channel inputs are shown under the sliders, from hex, rgb or hsl.

#### How do I use the color picker with the keyboard?

The saturation and brightness area is a two-dimensional slider: Left and Right change saturation, Up and Down change brightness, and Shift makes steps of 10. Page Up and Down adjust brightness by 10, and Home and End set saturation to 0 or 100. Hue and opacity are sliders.

#### Can users pick a color from anywhere on the screen?

Yes, where the browser supports it. The eyedropper button only appears when window.EyeDropper exists, so it is hidden in browsers without it. Turn it off with eyeDropper={false}. A copy button is also on by default, and copyButton={false} removes it.

#### How do I disable transparency or reword the labels?

Set alpha={false} to hide the opacity slider and channel. Every UI string, including the accessible names of the area, sliders and inputs, can be replaced by passing a partial labels object. Use variant="plain" to drop the glass card surface when placing it inside your own popover.

### Accessibility

- The trigger is a labeled button showing the chosen date; the calendar opens in a popover, or as a swipe-to-close bottom sheet on phones.
- Focus lands on the selected day (or today) and returns to the field on close; the sheet keeps the field above the software keyboard.

### When to use the date picker

- Use it as a mobile-friendly date picker, a popover on desktop and a bottom sheet on phones, for a check-in field on a hotel or rental form where people type nothing and instead open a calendar from a labeled button, with min set to today so past dates are unavailable.
- Use DateRangePicker when you need a start and an end, for example a reporting period, where its presets such as Next 7 days let people skip the grid entirely.
- Use it in a form posted to a server: the name prop submits the chosen day as YYYY-MM-DD, so a plain form action or FormData read gets a predictable string.
- Skip it when the calendar should be permanently visible on the page, as in a scheduling sidebar; Calendar on its own does that, without the field, popover or sheet around it.
- Pair it with its own description and error props for helper text and the message, Button for a custom reset action beside it, and the calendarLabels prop when translating the grid inside the popup.


### Frequently asked questions

#### How does the React date picker behave on a phone?

From 640px up it opens as a glass popover under the field. On phones it becomes a full-width bottom sheet built on Base UI Drawer that you can swipe down to close, with larger finger-sized days. Both fade instead of springing when reduced motion is on.

#### Which keys open the date picker and move around it?

Enter, Space or the Down arrow on the field opens it. Inside, arrows move by day and week, Page Up and Page Down change month, and Shift with them changes year. Enter or Space picks, Escape closes and returns focus to the field, and Tab stays inside the popup.

#### How do I control the open state or keep the popup open after picking?

Use open, defaultOpen and onOpenChange for the popup. By default it closes when a date is picked; set closeOnSelect={false} to keep it open. clearable (on by default) shows a clear button once there is a value, and showFooter (also on by default) controls the Today and Clear buttons.

#### Why does my prerendered date picker mismatch on hydration?

A changing today causes hydration mismatches, so pass today a fixed date on prerendered pages. Also set locale explicitly so server and browser format the field the same way. formatOptions takes Intl.DateTimeFormatOptions to control how the chosen date is displayed in the field.

### Example 3 of 5: With react-hook-form

Field takes the error from the form library: Controller hands the control its ref, name, value and onBlur, and the message becomes FieldError's children. The preview below runs the same markup on plain state.

```tsx
type Values = { name: string };

export function Example() {
  const { control, handleSubmit } = useForm<Values>({ defaultValues: { name: "" } });

  return (
    <form onSubmit={handleSubmit((values) => console.log(values))} className="flex max-w-sm flex-col gap-4">
      <Controller
        name="name"
        control={control}
        rules={{ required: "Name is required." }}
        render={({ field, fieldState }) => (
          <Field required invalid={fieldState.invalid}>
            <FieldLabel>Full name</FieldLabel>
            <FieldControl>
              <Input {...field} />
            </FieldControl>
            <FieldError>{fieldState.error?.message}</FieldError>
```

### Example 4 of 5: One size scale for buttons and fields

```tsx
  return (
```

### Accessibility

- FieldLabel is a real <label for> pointing at the control, so the control has an accessible name and a larger click target.
- FieldDescription and FieldError ids are added to the control's aria-describedby only while they are rendered, merged with any aria-describedby the control already has.
- FieldError is role="alert", so an error that appears after a submit or a blur is announced; it renders only while the field is invalid.
- The required asterisk is aria-hidden; the control itself gets required, so assistive tech says it once.
- Form libraries: every SheenUI input forwards ref, onBlur, name, required, disabled, aria-invalid and aria-describedby, so Field works with react-hook-form's Controller (pass invalid={fieldState.invalid} and the message as FieldError's children).

### All exports on this page

- Field — A form field wrapper that wires a label, a description and an error message to any control.
- FieldControl — Wires the one control inside it to its Field: the element gets id, aria-describedby, aria-invalid, required and disabled.
- FieldDescription — Muted helper text under the control; its id is added to the control's aria-describedby while it is rendered.
- FieldError — The error message of a Field.
- FieldLabel — The label of a Field: Label already pointing at the field's control, with the required asterisk.
- Label — A text label for a control.
- groupBlur — Wraps onBlur for a control made of several focusable parts: it fires only when focus leaves the whole group.
- mergeRefs — Combine refs (callback or object) into one callback ref; undefined entries are skipped.
- useField — The state of the surrounding Field (invalid, required, disabled, controlId).
- useFocusProxyRef — A ref for a control made of several focusable parts (a radio group, a rating, an OTP field).
- useMergedRef — mergeRefs as a hook: returns one stable callback ref that forwards the node to every ref passed in, always the latest ones.


### When to use the Field and Label

- Use it as a react-hook-form field wrapper around a native input, a Slider or a Switch that does not draw its own label, so the label names the control and the description and error are read together with it.
- Use it with react-hook-form: pass invalid={fieldState.invalid} to Field and put the validation message inside FieldError, and the control gets aria-invalid automatically.
- Use it to build a settings row such as a webhook URL with helper text, where a FieldDescription explains the format and a FieldError appears only after a failed save.
- Skip it when the control already takes label, description and error props; Input, Select and the other SheenUI form components wire those themselves, so wrapping them adds nothing.
- Pair it with FieldControl around a native input or your own component, with Slider or Switch, which join the field on their own, and with the useField hook when writing your own field parts.


### Frequently asked questions

#### How do I build an accessible React form field with a label and error?

Nest FieldLabel, one control inside FieldControl, and optional FieldDescription and FieldError in a Field. It generates the ids, so the label's for points at the control and aria-describedby lists the description and the error, but only while they are rendered.

#### What does the invalid prop actually change?

Setting invalid shows FieldError and puts aria-invalid on the control. FieldError has role="alert", so the message is announced when it appears, and it rises into place by 6px unless reduced motion is on. The required and disabled props reach the control too.

#### Does Field add extra tab stops or change focus?

No. Field adds no tab stops; it only wires ids and state. Clicking the label focuses the control. The required asterisk is hidden from screen readers because the control itself carries the required attribute, so it is not announced twice.

#### How can I read the field state inside my own component?

Call useField inside a Field. It returns controlId, invalid, required and disabled, or null outside a Field. The ids and aria wiring themselves are handled by Base UI Field, or by FieldControl for a native element. That lets you build a custom hint or counter that reacts to the invalid state.

```tsx
import { useState } from "react";
import { FileUpload } from "@/components/sheenui/file-upload/file-upload";

// Package build (after the first npm release, or a packed tarball): import { FileUpload, type FileUploadHandler, type FileUploadItem } from "@sheenui/theme";

// Your uploader: report progress, honor the abort signal, throw to fail.
async function uploadWithProgress(
  url: string,
  file: File,
  { onProgress, signal }: { onProgress: (percent: number) => void; signal: AbortSignal },
) {
  // XMLHttpRequest (or fetch + a stream) goes here; call onProgress(0..100) as bytes leave.
  onProgress(100);
  await fetch(url, { method: "POST", body: file, signal });
}

export function Example() {
  const [files, setFiles] = useState<FileUploadItem[]>([]);
  const uploaded = files.filter((item) => item.status === "done").length;

    await uploadWithProgress("/api/files", file, { onProgress, signal });
  };

  return (

      <FileUpload
        label="Attachments"
        accept="image/*,.pdf"
        maxSize={5 * 1024 * 1024}
        maxFiles={6}
        upload={upload}
        onValueChange={setFiles}
      />
```

### Accessibility

- The group is role="group". Name the input with aria-label or a Field label: addon text is read as part of the page but is not the input's name unless you link it with aria-describedby.

### When to use the input group

- Use InputGroup for a URL field with an https:// prefix, a price with a currency symbol and a unit, or a search box with an Apply button on its right edge, all sharing one focus ring.

### Frequently asked questions

#### How do I step a React number input with the keyboard?

Focus the input and use Up and Down to step by step. Shift uses largeStep and Alt uses smallStep. Home and End jump to min and max. The stepper buttons are not tab stops, because the input already offers the same keys, and they repeat when held with a pointer.

#### Is the number field a spinbutton for screen readers?

No, deliberately. Base UI renders a text input with a decimal inputMode, announced as a Number field through aria-roledescription, so phones show a numeric keypad. There are no aria-valuenow, min or max attributes; the value is the text itself, and min and max clamp it.

#### How do I show currency, percent or units?

Pass format with any Intl.NumberFormat options, for example style currency with currency USD. It uses the visitor's locale unless you set locale. Typing and pasting are parsed back using the same format, and name submits the value with a form.

#### What is the odometer effect, and can I turn it off?

When the value steps through buttons, arrow keys, the wheel or scrub, the changing digits slide up or down like an odometer. While you type, the plain input shows. It is a decorative overlay and never animates with reduced motion or in high contrast mode.

```tsx
// Package build (after the first npm release, or a packed tarball): import { Button, RadioGroup, useToast } from "@sheenui/theme";

export function Example() {
  const [size, setSize] = useState<string | null>(null);
  const [error, setError] = useState<string>();
  const toast = useToast();

  function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    if (!size) {
      setError("Choose a size to continue.");
      // Take keyboard and screen-reader users straight to the choice.
      event.currentTarget.querySelector<HTMLElement>("[role=radio]")?.focus();
      return;
    }
    setError(undefined);
    toast.success("Added to bag", `Size ${size.toUpperCase()}`);
  }

  return (
    <form onSubmit={submit} noValidate className="flex flex-col items-start gap-4">
      <RadioGroup
        label="Size"
        orientation="horizontal"
        name="size"
        required
        value={size}
        onValueChange={(v) => {
          setSize(v);
          setError(undefined);
        }}
        error={error}
        items={["xs", "s", "m", "l", "xl"].map((v) => ({ value: v, label: v.toUpperCase() }))}
      />
      <Button type="submit">Add to bag</Button>
    </form>
  );
}
```

### When to use the radio group

- Use it as a radio card group for a pricing step where the user must pick exactly one plan, with variant="card" showing an icon, a description and a price in meta for each option.
- Use it for a checkout shipping choice such as Standard or Express, where each option needs a second line of text that a plain dropdown could not show next to the label.
- Use it for a short survey answer or a notification preference, with the classic variant giving a compact dot per option and a legend from the label prop.
- Skip it when the list is long or the choices are many; Select is better, Checkbox suits many-of-many answers, and SegmentedControl suits a few view modes rather than form answers.
- Pair it with Field-style helper text through description and error props, Badge in the meta slot for labels like Popular, and Button to submit the chosen value after name posts it.


### Frequently asked questions

#### How do I make selectable cards in a React radio group?

Set variant="card" and pass items with value, label, description, icon and meta, or compose RadioCard children yourself. The columns prop (1 to 4) and cardLayout (row, stack or auto) shape the grid, and the selection tint glides between cards using transform only.

#### Which keys move the selection in the radio group?

Tab enters the group once, on the chosen option or the first one. The arrow keys move the choice and select it, and Space selects the focused option. The group is role="radiogroup" named by the legend or aria-label, and each option is role="radio" with aria-checked.

#### Does it work as a controlled component?

Yes. Use value with onValueChange, or defaultValue for uncontrolled use. The label is the legend, error marks every radio invalid, and name submits the value with a form. It is built on Base UI RadioGroup inside Field and Fieldset, so description and error link to each radio.

#### Is there a limit on how many cards I can show?

Classic dots and cards are glass-1 surfaces, and the component docs advise that card groups should stay within a budget of 8 backdrop-filter surfaces in view. For longer lists, use Select instead. In forced colors a checked card gets a thick Highlight edge.

### Frequently asked questions

#### How do I make a segmented control in React with Tailwind?

Pass items as objects with value, label, optional icon, disabled and aria-label, then use value with onValueChange or defaultValue. It is a Base UI ToggleGroup with one pressed item, styled with Tailwind v4 and the SheenUI glass track.

#### Can the selection be empty?

No. It never ends up empty: pressing the chosen segment again keeps it chosen. That makes it suited to a required view mode. Use name to submit the value with a form, and size sm, md or lg and fullWidth to share the row equally.

#### Which keys and ARIA does the segmented control use?

Tab enters once on the chosen segment. The arrow keys move between segments, Home and End jump to the ends, and Enter or Space picks. Segments are toggle buttons with aria-pressed, so name the group with aria-label or aria-labelledby. Segments are 44px tall on touch screens.

#### Why does my segmented control overflow in a flex layout?

Like any shrinkable content, it needs a width-constrained parent. In a flex row or column that sizes to its content, give the parent min-w-0 and w-full so the adaptive steps can run. Without that, the container never gets narrower and nothing needs to adapt.
