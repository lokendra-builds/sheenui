### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| items | NavbarItem[] | required | Takes the navigation items, in order. |
| value | string | required | Sets the value of the active item when controlled. |
| onValueChange | ((value: string) => void) | optional, no default | Called with an item's value when it is chosen (a plain left click on a link also calls it). |
| brand | ReactNode | optional, no default | Shows the logo or product name on the left. |
| actions | ReactNode | optional, no default | Buttons on the right (theme toggle, sign in, ...). |
| renderLink | ((props: NavLinkProps, item: NavbarItem) => ReactElement) | a plain <a> | Render items that have an href through your router's link component. See NavLinkProps. |
| shrinkOnScroll | number \| false | 24 | Once the page scrolls past this many px, the bar tightens and turns more opaque (the floating pill also shrinks a touch). false turns it off. |
| hideOnScroll | number \| boolean | false | Slide the bar out of view while scrolling down and bring it back on any scroll up. true starts hiding after 64px; pass a number for a different distance. Make the navbar sticky or fixed for this to make sense. |
| scrollContainer | RefObject<HTMLElement \| null> | optional, no default | Track this element's scroll instead of the window's (e.g. an app shell's scrolling <main>). |
| variant | "floating" \| "bar" | "floating" | "floating" = centred glass pill, highlight morphs between items (Apple style). "bar" = full-width top bar, a sliding underline marks the active item. |
| collapsible | boolean | true | When the items don't fit next to the brand and actions (phones, narrow containers), fold them into a menu button that opens a glass popover. false lets them scroll sideways instead. |
| labels | Partial<NavbarLabels> | defaultNavbarLabels | Every string, for translation: { menu: "Menu", name: "Main" } (accessible name of the menu button shown when the items are folded away, and the default landmark name). Every other string, for translation: labels={{ menu: "…" }}; omitted keys keep the English of defaultNavbarLabels. All 2 keys of NavbarLabels are listed in the key table under the props table. |
| aria-label | string | labels.name | Landmark name. Give each navigation on a page its own, e.g. "Main" and "Account". |
| className | string | optional, no default | Extra classes for the <nav> (position it with sticky, fixed or margins). |

### Example 1 of 3: Floating pill

Click the items to watch the highlight morph.

```tsx
import { useState } from "react";
import { Button } from "@/components/sheenui/button/button";
import { Navbar } from "@/components/sheenui/navbar/navbar";
// Package build (after the first npm release, or a packed tarball): import { Button, Navbar } from "@sheenui/theme";

export function Example() {
  const [active, setActive] = useState("home");

  return (
    <Navbar
      aria-label="Main"
      brand={<span>Sheen</span>}
      items={[
        { value: "home", label: "Home" },
        { value: "work", label: "Work" },
        { value: "pricing", label: "Pricing" },
        { value: "blog", label: "Blog" },
      ]}
      value={active}
      onValueChange={setActive}
      actions={<Button size="sm">Sign in</Button>}
    />
  );
}
```

### Example 3 of 3: Folds into a menu

When the items don't fit next to the brand and actions, they fold into a menu button. It opens a glass popover listing every item, with the current one checked; choosing one closes it and returns focus to the button. Pick a width to watch it fold and unfold.

```tsx
import { useState } from "react";
import { Button } from "@/components/sheenui/button/button";
import { Navbar } from "@/components/sheenui/navbar/navbar";
// Package build (after the first npm release, or a packed tarball): import { Button, Navbar } from "@sheenui/theme";

const items = [
  { value: "home", label: "Home" },
  { value: "work", label: "Work" },
  { value: "pricing", label: "Pricing" },
  { value: "blog", label: "Blog" },
  { value: "docs", label: "Docs" },
  { value: "changelog", label: "Changelog" },
];

export function Example() {
  const [active, setActive] = useState("home");

  // Nothing to set up: the nav measures itself and folds when it must.

  return (
    <Navbar
      aria-label="Main"
      brand={<span>Sheen</span>}
      items={items}
      value={active}
      onValueChange={setActive}
      actions={<Button size="sm">Sign in</Button>}
      labels={{ menu: "Menu" }} // the menu button's name; collapsible={false} scrolls instead
    />
  );
}
```

| --- | --- |
| Tab / Shift + Tab | Move through the brand, items and actions. |
| Enter | Follow a link or select an item. |

### Accessibility

- A <nav> landmark: pass aria-label ("Main") and give a second bar a different name. The current item has aria-current="page".
- A bar hidden by hideOnScroll comes back when focus enters it, so keyboard users never tab into an off-screen bar.
- The folded menu button reports aria-expanded and is named by labels.menu. Targets are 44 px on touch screens.

### All exports on this page

- Navbar — Horizontal navigation.
- defaultNavbarLabels — The English NavbarLabels used when labels is omitted; a partial labels prop is merged over it.


### When to use Navbar

- Use it as a floating navbar, the glass pill, for a marketing site header with four or five destinations, where the highlight morphing between Home, Work, Pricing and Blog gives the page a polished, app-like first impression.
- Use variant="bar" for the top of a dashboard or documentation app, where a full-width header with a sliding underline and a Sign in action on the right is what users expect.
- It suits sites that must work on phones without a second mobile menu, because items that no longer fit next to the brand and actions fold into a menu button on their own.
- Skip it when your destinations open rich dropdown panels with descriptions and images; Navigation menu is built for that, while this component is a flat list of links or buttons.
- Pair it with Button for the Sign in action, GlassCard for the page sections underneath, and Avatar in the actions slot to show the signed-in user.


### Frequently asked questions

#### How do I build a glassmorphism navbar in React with SheenUI?

Import Navbar from @sheenui/theme and pass brand, items, value and onValueChange. The default variant is a floating glass pill with a morphing highlight. Add actions for a Button on the right, and position it with className, for example sticky or fixed plus top margin.

#### What happens when the items do not fit on a small screen?

With collapsible left at its default of true, the navbar measures itself and folds the items into a menu button that opens a glass popover. The current item shows a checkmark, choosing one closes the popover, and ArrowDown, ArrowUp, Home and End move between items while Escape closes it. Set collapsible={false} to scroll the items sideways instead.

#### How do I use it with React Router or Next.js links?

Give items an href and pass renderLink, a function that receives the link props and the item and returns your router's Link element. The same function renders the links inside the folded menu. Without renderLink, items with an href render as plain anchors. The component file starts with "use client".

#### Can the navbar hide or shrink while I scroll?

Yes. shrinkOnScroll tightens the bar after 24px of scrolling by default, or pass false to disable it. hideOnScroll slides it away while scrolling down and brings it back on any upward scroll or when focus enters it. Use scrollContainer to track an inner scrolling element instead of the window.

### Example: A site header with rich panels

Hover or focus Products: a featured card beside icon links. Move to Developers and the panel resizes while the content slides in from the side you came from.

```tsx
import { Button } from "@/components/sheenui/button/button";
import { NavigationMenu, NavigationMenuContent, NavigationMenuItem, NavigationMenuLink, NavigationMenuList, NavigationMenuTrigger } from "@/components/sheenui/navigation-menu/navigation-menu";
// Package build (after the first npm release, or a packed tarball): import { Button, NavigationMenu, NavigationMenuContent, NavigationMenuItem, NavigationMenuLink, NavigationMenuList, NavigationMenuTrigger } from "@sheenui/theme";

const products = [
  { title: "Charts", text: "Accessible chart components, each with a data table." },
  { title: "Blocks", text: "Login, checkout, settings and notification centre." },
  { title: "Dashboards", text: "Five analytics templates with live data." },
];

export function Example() {
  return (
    <div className="glass-2 flex items-center gap-3 rounded-sheen-full py-2 ps-5 pe-2">
      <strong>Acme</strong>
      <NavigationMenu aria-label="Main">
        <NavigationMenuList>
          <NavigationMenuItem value="products">
            <NavigationMenuTrigger>Products</NavigationMenuTrigger>
            <NavigationMenuContent className="w-[min(40rem,calc(100vw-2rem))]">
              <div className="grid gap-2 sm:grid-cols-[13rem_1fr]">
                <NavigationMenuLink plain href="#featured" className="flex flex-col justify-end gap-1 rounded-sheen-lg p-4 text-white [background-image:linear-gradient(160deg,var(--sheen-accent),oklch(55%_0.2_320))]">
                  <span className="text-base font-semibold">Liquid Glass</span>
                  <span className="text-xs">Real refraction for hero surfaces.</span>
                </NavigationMenuLink>
                <ul className="m-0 grid list-none gap-1 p-0">
                  {products.map((p) => (
                    <li key={p.title}>
                      <NavigationMenuLink plain href={`#${p.title.toLowerCase()}`}>
                        <span className="block text-sm font-medium text-sheen-fg">{p.title}</span>
                        <span className="block text-xs text-sheen-fg-muted">{p.text}</span>
                      </NavigationMenuLink>
                    </li>
                  ))}
                </ul>
              </div>
            </NavigationMenuContent>
          </NavigationMenuItem>
          <NavigationMenuItem>
            <NavigationMenuLink href="#pricing" active>Pricing</NavigationMenuLink>
          </NavigationMenuItem>
        </NavigationMenuList>
      </NavigationMenu>
      <Button size="sm" className="ms-auto">Sign in</Button>
    </div>
  );
}
```

### Keyboard

| Keys | Action |
| --- | --- |
| Tab | Enters the bar; Tab again moves into an open panel's links and then out. |
| ← / → | Move between the items of the bar. |
| Enter / Space / ↓ | Open the focused item's panel and move into it. |
| Escape | Close the panel and return focus to its trigger. |

### Accessibility

- Renders a <nav> landmark: give it an aria-label ("Main", "Docs") so it is told apart from other navigation.
- Triggers are buttons with aria-expanded and aria-controls; links use aria-current="page" when active.
- The dropdown is not a menu role: it is a region of ordinary links, which is what site navigation should be.
- Hover opens after delay (120 ms) and closes after closeDelay (150 ms); clicking and the keyboard open it at once, so touch and keyboard users never depend on hover.
- On touch screens targets are 44px. Under reduced motion the panel fades and does not resize or slide.

### When to use the navigation menu

- Use it as a mega menu for a product site header where Products, Solutions and Resources each open a panel of titled links with short descriptions, the kind of mega-menu pattern that a flat list of links cannot carry.
- Use it for a documentation site whose top bar groups guides, API reference and examples, so visitors can scan every section from one shared glass panel without leaving the current page.
- The shared panel resizes to each item's content and slides between items, so it suits menus with panels of different sizes, from a three-link list to a grid up to 36rem wide.
- Skip it when you only have a handful of plain links with no dropdowns; Horizontal nav is simpler and folds into a menu on narrow screens, while Menu is the right tool for action lists.
- Pair it with Button for a call to action beside the bar, Badge for a New label inside a panel link, and Drawer to hold the navigation on phones.


### Frequently asked questions

#### How do I build a react navigation menu with dropdown panels?

Compose NavigationMenu, NavigationMenuList and one NavigationMenuItem per entry. Inside an item put a NavigationMenuTrigger and a NavigationMenuContent holding NavigationMenuLink elements, or use a link directly for items with no panel. Give the root an aria-label such as Main.

#### Is the dropdown a menu role? How does keyboard navigation work?

No. The panel is a region of ordinary links, which is what site navigation needs. Left and Right arrows move between bar items, Enter, Space or Down opens the focused item's panel and moves into it, Tab walks the panel's links, and Escape closes it and returns focus to the trigger.

#### Does it only open on hover?

No. Hover opens a panel after the delay prop, 120 ms by default, and closes it after closeDelay, 150 ms, so crossing the bar does not flicker. Clicking or using the keyboard opens it immediately, so touch and keyboard users never depend on hover.

#### How do I use my router's link component inside the panel?

NavigationMenuLink accepts a render prop that swaps the anchor for your router link. Use the plain prop to skip the pill styling when the link sits inside a panel, and closeOnClick to control whether choosing it closes the panel. Active links get aria-current="page".

### Example 1 of 3: A full app shell

### Accessibility

- A <nav> landmark (aria-label defaults to "Sidebar"; change it when a page has more than one).
- Group headings are buttons with aria-expanded; closed items leave the tab order. The current page uses aria-current="page".
- In the collapsed rail the labels stay as accessible names and as title tooltips; the icons are decorative.
- Targets are 44px on touch screens. Under reduced motion the groups jump open and shut.

### All exports on this page

- Sidebar — The app-shell sidebar: a glass column with a header, groups of links that fold open and shut, and a footer.
- SidebarFooter — The bottom of a Sidebar, pushed down by mt-auto: a user menu or a help link.
- SidebarGroup — A collapsible section of a Sidebar: a heading button and the items under it.
- SidebarHeader — The top of a Sidebar: a logo or a workspace switcher.
- SidebarItem — One link (or, without href, one button) of a Sidebar.
- defaultSidebarLabels — The English SidebarLabels used when labels is omitted; a partial labels prop is merged over it.
- useSidebar — Whether the surrounding Sidebar is collapsed to its icon rail.


### When to use Sidebar

- Use Sidebar for the left navigation of an admin or dashboard app, where groups of links collapse, badges show unread counts and the whole column folds down to an icon rail.
- Use collapsed to turn it into an icon rail on a narrow layout. Labels stay available as accessible names and title tooltips.
- Give the nav an aria-label such as Workspace and mark the current page with the active prop, which sets aria-current="page".
- Skip it for a short flat list of sections. VerticalNav is shorter, and Navbar suits a top bar on a marketing site.
- Pair it with Drawer for a phone menu, Badge in SidebarItem for counts, and Breadcrumb inside the page header.


### Frequently asked questions

#### How do I build a collapsible sidebar in React?

Compose SidebarHeader, SidebarGroup (a section with a label and defaultOpen), SidebarItem and SidebarFooter inside Sidebar. Groups fold open and shut with the shared height animation.

#### How does the keyboard work?

Tab moves through group headings and items in order. Enter or Space opens or closes a group and activates an item. Group headings are real buttons with aria-expanded.

#### What does collapsed do?

It turns the sidebar into an icon rail: labels become accessible names, groups lose their headings, and the width shrinks. Control it from your own button.

#### Sidebar or VerticalNav?

Use VerticalNav for a flat list with one selected value. Use Sidebar when you need collapsible groups or your own header and footer content.

#### Do toggle buttons inside a group keep their pressed state?

Yes. The group adds no state of its own: each button keeps its own name and state, so a toggle keeps aria-pressed, and disabled buttons are skipped by the arrow keys. Name the group with aria-label when the buttons share one meaning.

#### Which variant and size should the buttons use?

Any variant, but the same size, so the joined edges line up. The group squares the corners where buttons touch, overlaps their edges by a pixel and lifts the focused button above its neighbours; the buttons keep their own hover and press motion.

### Frequently asked questions

#### How do I build a glass sidebar in React?

Render VerticalNav with sections, value and onValueChange. Each section takes an optional title and items shaped as value, label, icon, badge, href and disabled. Use header for a logo and footer for a user card. The nav fills its parent's height, so set one on className or the parent.

#### How does the collapsed icon rail stay accessible?

Every item keeps its text as an accessible name when collapsed, and the label shows in a tooltip on hover and focus. The rail is a nav with a list, the current item carries aria-current="page", and under reduced motion the rail snaps open and shut in one frame.

#### Can items be real links with my router?

Yes. Give an item an href and pass renderLink, a function receiving the link props and the item that returns your router's Link element. Items without an href render as buttons. Tab moves between items, Enter follows a link, and Enter or Space presses a button item.

#### How do I name the sidebar when there are several navigations?

Pass aria-label, which defaults to Sidebar. Give each navigation landmark on the page its own name, for example Workspace for the sidebar and Main for a top bar, so screen reader users can tell the regions apart in the landmarks list.
