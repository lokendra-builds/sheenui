## About components

### Overview

Pick a glassy part and copy it. Every one of the 67 pages below is a glass React component with a live demo, the props, the keyboard model and the exact files to copy, so you can take a single button or a whole form kit without installing a package. The set grows from the same foundation: three glass levels, a handful of [glass design tokens](https://lokendra-builds.github.io/sheenui/foundations), and shared motion presets.

The components are grouped the way you build screens. Components are the everyday parts, such as the [glass button](https://lokendra-builds.github.io/sheenui/components/button), [glassmorphism card](https://lokendra-builds.github.io/sheenui/components/glass-card), [modal dialog](https://lokendra-builds.github.io/sheenui/components/dialog) and [data table](https://lokendra-builds.github.io/sheenui/components/data-table). Forms cover inputs, pickers and uploads, Overlays hold menus, drawers and command palettes, and Navigation and Layout give you the frame around them.

Looking for motion? The [animated React components](https://lokendra-builds.github.io/sheenui/effects/) page lists the effects built with Motion. Need whole screens? See the [React Tailwind blocks](https://lokendra-builds.github.io/sheenui/blocks/) and the [glassmorphism dashboard templates](https://lokendra-builds.github.io/sheenui/dashboards/). Charts live on [their own gallery](https://lokendra-builds.github.io/sheenui/charts/), and the [installation guide](https://lokendra-builds.github.io/sheenui/docs/installation) shows how to add any of these with the shadcn CLI; the [Tailwind CSS v4 setup](https://lokendra-builds.github.io/sheenui/docs/tailwind-v4) covers the two CSS imports.

Everything is free and MIT licensed, built on Base UI and Tailwind CSS v4, and checked in light and dark, in both style presets and with reduced motion on. New to glass UI? Start with the [glassmorphism React tutorial](https://lokendra-builds.github.io/sheenui/guides/glassmorphism-react-tutorial).

### Frequently asked questions

### What are glass UI components?

Glass UI components are interface parts such as buttons, cards, dialogs and menus drawn as frosted glass: a translucent tint, a backdrop blur and a lit border over a colorful background. SheenUI adds Liquid Glass refraction on top, and a solid fallback for people who turn transparency off.

### Which library are the components built on?

Behavior, focus handling and ARIA come from Base UI's headless primitives, the styling is Tailwind CSS v4, and the animation is Motion. You copy the source into your own project.

### Are the components accessible?

Each page lists its keyboard model and accessibility notes. Every component is tested with axe and a keyboard, and glass turns into solid surfaces with reduced transparency, more contrast or Windows High Contrast.


## All exports on this page

- classNameWith — Base UI's className is a string OR a function of the part's state.
- cn — Merge class names, letting later Tailwind classes override earlier ones.
- useLatest — A ref that always holds the latest value, for stable callbacks that must read current props or state without becoming dependencies.
- useSyncRef — Keeps an existing ref in step with value: the same layout-effect update as useLatest.
