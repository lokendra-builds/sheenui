## About blocks

### Overview

Blocks are complete sections you can paste into an app and ship, from a glassy login page to a full dashboard. Each of the 20 blocks below is built only from SheenUI components, so spacing, glass levels and motion already match, which makes them free React UI blocks under the MIT licence and ready-made landing page sections for Tailwind. You get a live demo, the code, the keyboard notes and the list of files to copy, and the same React and Tailwind source works in Vite, Next.js and any other React 19 setup.

Start with authentication: a [glassmorphism login form](https://lokendra-builds.github.io/sheenui/blocks/glass-login), a split-screen [sign-up page](https://lokendra-builds.github.io/sheenui/blocks/signup-page) and an [OTP verification page](https://lokendra-builds.github.io/sheenui/blocks/otp-verification). For selling, there is a [pricing table](https://lokendra-builds.github.io/sheenui/blocks/pricing) and a [checkout form](https://lokendra-builds.github.io/sheenui/blocks/payment-checkout). For product screens, see the [AI chat UI](https://lokendra-builds.github.io/sheenui/blocks/ai-chat), the [chat app](https://lokendra-builds.github.io/sheenui/blocks/chat-app), a [settings page](https://lokendra-builds.github.io/sheenui/blocks/settings-page), a [notification center](https://lokendra-builds.github.io/sheenui/blocks/notification-center) and a [bento grid](https://lokendra-builds.github.io/sheenui/blocks/bento-grid).

Looking for full analytics screens? The [glassmorphism dashboard templates](https://lokendra-builds.github.io/sheenui/dashboards/) have their own page, with five complete dashboards that use the [animated React charts](https://lokendra-builds.github.io/sheenui/charts/). If you would rather assemble your own, browse the [glass UI components](https://lokendra-builds.github.io/sheenui/components/) they are made from, and read the [glassmorphism React tutorial](https://lokendra-builds.github.io/sheenui/guides/glassmorphism-react-tutorial) to see how the surface works. To add a block to your app, follow the [installation page](https://lokendra-builds.github.io/sheenui/docs/installation) and the [Tailwind CSS v4 setup](https://lokendra-builds.github.io/sheenui/docs/tailwind-v4).

### Frequently asked questions

### What is a block?

A block is a ready-made section or screen, such as a login form, a pricing table or an AI chat, assembled only from SheenUI components so it matches the rest of your interface.

### How do I add a block to my project?

Every block page lists its files to copy, and the registry installs it with one shadcn command. The installation page shows the steps.

### Can I change the blocks?

Yes. They are plain React source in your repository, with Tailwind classes you can edit; nothing is hidden in a package.
