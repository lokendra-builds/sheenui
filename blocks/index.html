React Tailwind Blocks and Templates

React Tailwind blocks in glass: login, pricing, checkout and AI chat, ready to copy.

Blocks (20)

  • Glass login

    A React glass login page, a glassmorphism login form with validation, a password reveal, a loading state and social sign-in buttons, built from SheenUI's Button, GlassCard and Input.

  • Lamp login

    A dark stage with a pull cord: pull it and a warm light cone reveals a glass sign-in card. The card is always there for keyboards and screen readers.

  • OTP verification

    A glass OTP verification page for React that submits on the last digit, shakes on a wrong code and counts down to resend.

  • Payment checkout

    A glass React checkout form for card or UPI payments, with a live card preview, input formatting and an order summary.

  • Dashboard stats

    Dashboard stat cards for React are glass KPI cards whose numbers count up, sparklines draw in and periods switch with a sliding pill.

  • AI chat

    An AI chat UI for React with replies that stream in word by word, a “thinking” shimmer, Markdown with code blocks and a model picker.

  • Sign-up page

    A split-screen sign-up page for React: an animated brand panel beside a glass form with social sign-up and a live password-strength meter.

  • Bento grid

    A glassmorphism bento grid for React whose cells run live mini-demos built from real SheenUI components.

  • Chat app

    A complete React chat app template: the chat list and the open chat side by side, stacking into list then chat on narrow screens.

  • Notification center

    A React notification center: a bell with a live unread count that opens a glass inbox with tabs, day groups and inline actions.

  • Pricing

    A glass React pricing table with a monthly/yearly toggle, prices that roll like an odometer and a full comparison table.

  • Settings page

    A complete React settings page with a scroll-spy side nav, profile upload, notification switches and a glass save bar.

  • Hero section

    This React hero section is a landing-page block that sets a display headline, a lede and calls to action over any backdrop, with a glass frame for your product shot and a logo strip.

  • Feature grid

    This React feature grid is a marketing block that lays icon, title and text cards out in two to four columns by its own width, with one optional highlight card that is tinted, lit and spans two columns.

  • Testimonials

    These React testimonials are a social-proof block that shows customer quotes on glass cards, as a grid or as a marquee in one or two rows that rests on hover, focus, off-screen and with a Pause button.

  • FAQ section

    This React FAQ section is a block that shows questions in a glass accordion with find-in-page, and a faqPageJsonLd helper that returns the schema.org FAQPage object for the same questions.

  • Contact form

    This React contact form is a block with name, email and message fields, inline validation, a loading button and a success seal that lights green, working with a plain onSubmit or with react-hook-form.

  • Site footer

    This React site footer is a block on glass with link columns that are navigation landmarks, a newsletter field with validation, social icon links and a legal row.

  • 404 page

    This React 404 page is a not-found block with a large code whose zeros are glass rings, a plain explanation, a slot for your search field, a way back and suggested links.

  • Announcement banner

    This React announcement banner is a dismissible top bar on glass with a tone, a link and static copy, which reports the dismissal through a callback instead of storing it.

About blocks

Blocks are complete sections you can paste into an app and ship, from a glassy login page to a full dashboard. Each of the 20 blocks below is built only from SheenUI components, so spacing, glass levels and motion already match, which makes them free React UI blocks under the MIT licence and ready-made landing page sections for Tailwind. You get a live demo, the code, the keyboard notes and the list of files to copy, and the same React and Tailwind source works in Vite, Next.js and any other React 19 setup.

Start with authentication: a glassmorphism login form, a split-screen sign-up page and an OTP verification page. For selling, there is a pricing table and a checkout form. For product screens, see the AI chat UI, the chat app, a settings page, a notification center and a bento grid.

Looking for full analytics screens? The glassmorphism dashboard templates have their own page, with five complete dashboards that use the animated React charts. If you would rather assemble your own, browse the glass UI components they are made from, and read the glassmorphism React tutorial to see how the surface works. To add a block to your app, follow the installation page and the Tailwind CSS v4 setup.
