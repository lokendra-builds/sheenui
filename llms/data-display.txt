### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| children | ReactNode | optional, no default | Each child becomes one slide of the carousel. |
| aria-label | string | required | Accessible name of the carousel, e.g. "Featured products". Required. |
| slidesPerView | number \| Record<number, number> | 1 | Slides visible at once. A number, or breakpoints keyed by the carousel's own width in px (container width, not the window): { 0: 1.15, 640: 2, 1024: 3 }. Fractions show a peek of the next slide. |
| gap | number | 16 | Sets the space left between slides, in px. |
| align | "center" \| "start" | "start" | Where the current slide sits: at the start, or centred (great with a fractional view + loop). |
| loop | boolean | false | Endless in both directions. Needs enough slides to fill the view plus one; otherwise it rewinds. |
| slidesToScroll | number \| "page" | 1 | How far the arrows move: a number of slides, or "page" (the slides in view). |
| autoplay | number \| boolean | false | Advance on its own: true (every 5 s) or an interval in ms. Never starts by itself under reduced motion. |
| arrows | false \| "bottom" \| "overlay" | "bottom" | "bottom": in the control row. "overlay": floating on the slides' edges. false: none. |
| dots | boolean | true | Show the dots (a "3 / 12" counter replaces them when they don't fit). |
| index | number | optional, no default | Controlled position (snap index; with loop, the slide index). Update it from onIndexChange. |
| defaultIndex | number | 0 | Sets the starting position when uncontrolled. |
| onIndexChange | ((index: number) => void) | optional, no default | A user or autoplay move asks for a new position (never fired on mount or when following index). |
| effect | "none" \| "scale" | "none" | "scale": slides away from the current one shrink a little (transform only). |
| labels | Partial<CarouselLabels> | defaultCarouselLabels | Every other string, for translation: labels={{ carousel: "…" }}; omitted keys keep the English of defaultCarouselLabels. All 14 keys of CarouselLabels are listed in the key table under the props table. |
| slideClassName | string | optional, no default | Adds extra classes to each slide wrapper. |

### Example 1 of 4: Gallery with autoplay

One slide per view, loop, overlay arrows, autoplay every 5 s. The active dot fills as the next slide nears; hover, drag or Tab into it to pause, and use the pause button to stop it. Under reduced motion autoplay waits for Play. The overlay arrows sit on a page-colored veil with a two-tone focus ring, so they stay legible on any image; ←/→ work on them too.

```tsx
import { Carousel } from "@/components/sheenui/carousel/carousel";
import { CarouselCaption } from "@/components/sheenui/carousel/carousel-caption";
// Package build (after the first npm release, or a packed tarball): import { Carousel, CarouselCaption } from "@sheenui/theme";

const scenes = [
  { title: "Dunes", from: "from-amber-300", to: "to-rose-500" },
  { title: "Glacier", from: "from-sky-200", to: "to-indigo-500" },
  { title: "Forest", from: "from-lime-300", to: "to-emerald-700" },
];

function Scene({ title, from, to }: (typeof scenes)[number]) {
  return (
    <div className={`relative aspect-video overflow-hidden rounded-sheen-lg bg-gradient-to-br ${from} ${to}`}>
      {/* The caption bar carries its own dark scrim, so the words stay readable over any image. */}
      <CarouselCaption>{title}</CarouselCaption>
    </div>
  );
}

export function Example() {
  return (
    <Carousel aria-label="Landscapes" loop autoplay={5000} arrows="overlay">
      {scenes.map((scene) => (
        <Scene key={scene.title} {...scene} />
      ))}
    </Carousel>
  );
}
```

### Example 2 of 4: Responsive cards

Slides per view follow the carousel's own width: 1.15 on phones (a peek of the next card), 2 from 560px, 3 from 900px. Arrows move a page at a time; the ends rubber-band. With several cards in view, the dots and announcements name the range (“Slides 4 to 6 of 6”).

```tsx
import { Carousel } from "@/components/sheenui/carousel/carousel";
// Package build (after the first npm release, or a packed tarball): import { Carousel } from "@sheenui/theme";

const products = [
  { name: "Dashboard", price: "$49" },
  { name: "Landing page", price: "$29" },
  { name: "Docs site", price: "$39" },
  { name: "Admin panel", price: "$59" },
];

function ProductCard({ name, price }: (typeof products)[number]) {
  return (
    <div className="glass-1 flex flex-col gap-1 rounded-sheen-lg p-5">
      <h3 className="font-semibold">{name}</h3>
      <p className="text-sm text-sheen-fg-muted">{price}</p>
    </div>
  );
}

export function Example() {
  return (
    <Carousel
      aria-label="Templates"
      slidesPerView={{ 0: 1.15, 560: 2, 900: 3 }}
      slidesToScroll="page"
      gap={16}
    >
      {products.map((p) => (
        <ProductCard key={p.name} {...p} />
      ))}
    </Carousel>
  );
}
```

### Accessibility

- Follows the WAI-ARIA carousel pattern: aria-roledescription="carousel", slides as groups named "3 of 8", and a polite live region that announces the slide after you navigate.
- Off-screen slides are inert. Autoplay pauses on hover, drag, a hidden tab or when off-screen, and stops for good when keyboard focus enters (press Play to resume).
- Under reduced motion autoplay does not start and slides change without a glide.

### When to use Carousel

- Use it as a React carousel with swipe for a product gallery with one slide per view, loop, overlay arrows and autoplay every five seconds, where users can also swipe, drag or use the dots. Use it as an image slider in Tailwind for a gallery or a row of testimonials, where children are the slides and swipe, arrows and dots come with it.
- Use slidesPerView breakpoints for a row of testimonial or product cards, such as 1.15 on phones to peek at the next card and 2 or 3 as the carousel widens. Set loop for an infinite loop carousel in React, where the last slide wraps around to the first.
- Use align="center" with effect="scale" for a featured showcase where neighbors peek on both sides and slides shrink as they leave the center.
- Skip it when users need to compare all items at once or when the content is critical; a grid or a Tabs panel shows everything, and Scroll area suits a simple sideways list.
- Pair it with GlassCard for slide content, Button for call-to-action links on slides, and Badge for labels over images.


### Frequently asked questions

#### How do I make a react carousel with loop and autoplay?

Render Carousel with one child per slide and a required aria-label. Set loop for an endless carousel that wraps without cloning slides, and autoplay to true for 5000 ms or a number of milliseconds. Autoplay pauses on hover, drag, a hidden tab or off screen, and stops when keyboard focus enters.

#### Is the carousel keyboard and screen reader friendly?

It follows the WAI-ARIA carousel pattern: aria-roledescription="carousel", slides named like "3 of 8", and a polite live region announcing the slide after you navigate. On the pause button, dots and arrows, Left and Right move, and Home and End jump to the first or last slide. Off-screen slides are inert, so Tab cannot reach hidden content.

#### How do I control it from outside and translate it?

Use index with onIndexChange for a controlled carousel, or defaultIndex for an uncontrolled one. onIndexChange is not called on mount. The labels prop holds every string, including slide names, arrows, dots and play and pause, and right-to-left pages mirror the layout, with the arrow keys swapped.

#### What happens with reduced motion?

Autoplay never starts by itself under reduced motion and waits until the user presses Play, and slides snap into place instead of gliding, although dragging still follows the finger. Use arrows set to bottom, overlay or false to place or remove the buttons, and dots to show or hide the dots.

### When to use the code block

- Use it as a syntax highlighter in documentation and blog posts to show a file with a filename tab, line numbers and highlightLines for the two or three lines the paragraph is explaining.

### Frequently asked questions

#### How do I add a react code block with a copy button?

Render CodeBlock with the code string and a language. A copy button is shown by default, copyable controls it, and onCopy fires after a successful copy. A successful copy is announced politely, and if the clipboard and its fallback both fail, the code is selected so the user can copy it by hand.

#### Which languages does the syntax highlighting support?

A small built-in tokenizer covers ts, tsx, js, jsx, json, css, bash, python, html and text, with aliases such as typescript, sh and py. There is no highlighting dependency to install. Colors are CSS variables like --sheen-code-keyword that you can override on the block or any ancestor.

#### How are long lines and line numbers handled?

Unwrapped, a long line scrolls inside the block while the line numbers stay pinned, and the code area becomes keyboard-focusable only when it scrolls. The wrap toggle in the header, or defaultWrap, wraps lines. Line numbers are left out of copy and from screen readers.

#### Does it work in right-to-left pages?

Code always reads left to right, and the block carries translate="no" so browsers do not translate it. The code area is a named region such as Code: button.tsx. Use the labels prop to translate the copy, wrap and region strings, and startLineNumber when showing an excerpt.

#### What is the difference between a react meter and a progress bar?

### Skeleton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| shape | "circle" \| "rect" \| "text" \| "pill" | "rect" | rect (rounded box, default), text (one line), pill (button / chip), circle (avatar). |
| width | string \| number | optional, no default | CSS width: a number is px, a string is used as is ("60%", "12rem"). |
| height | string \| number | their width | CSS height: a number is px, a string is used as is. Circles default to their width. |
| shimmer | boolean | true | Sweep of light across the shape. Never drawn under reduced motion. |

### SkeletonText

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| lines | number | 3 | Number of lines (0 renders none). |
| size | "sm" \| "md" \| "lg" \| "heading" \| "xs" | "md" | Matches the text it stands in for: xs 12px … lg 18px body text, or a heading. |
| lastLineWidth | string | "62%" | Width of the last line (it is usually shorter). |
| shimmer | boolean | true | Sets the sweep of light across the lines. |
| labels | Partial<SkeletonLabels> | defaultSkeletonLabels | When labels.loading is set, the block announces itself as a loading region (role="status"). Every other string, for translation: labels={{ loading: "…" }}; omitted keys keep the English of defaultSkeletonLabels. Its only key is listed in the key table under the props table. |

| --- | --- | --- | --- |

| rows | number | 4 | Number of rows (0 renders none). |

### Example 1 of 2: Presets

SkeletonCard and SkeletonList match a real card and list line for line: text skeletons use the same line boxes as the text (20px for 14px text), so nothing jumps when the content arrives. Each preset is one named loading region, never one label per line.

```tsx
import { SkeletonCard, SkeletonList } from "@/components/sheenui/skeleton/skeleton";
// Package build (after the first npm release, or a packed tarball): import { SkeletonCard, SkeletonList } from "@sheenui/theme";

export function Example({ loading }: { loading: boolean }) {
  return (
    <>
      {loading ? <SkeletonCard labels={{ loading: "Loading article" }} /> : <article>Your article card</article>}
      {loading ? <SkeletonList rows={4} labels={{ loading: "Loading activity" }} /> : <ul>Your activity list</ul>}
    </>
  );
}
```

### Example 2 of 2: Building blocks

Compose your own from Skeleton (rect, text, pill, circle), SkeletonText, SkeletonCircle and SkeletonRect. Wrap them in SkeletonGroup: it names the loading region once, and one beam of light crosses the whole group, every shape in step wherever it sits.

```tsx
import { Skeleton, SkeletonCircle, SkeletonGroup, SkeletonRect, SkeletonText } from "@/components/sheenui/skeleton/skeleton";
// Package build (after the first npm release, or a packed tarball): import { Skeleton, SkeletonCircle, SkeletonGroup, SkeletonRect, SkeletonText } from "@sheenui/theme";

export function Example() {
  return (
    <SkeletonGroup labels={{ loading: "Loading profile" }} className="glass-2 rounded-sheen-lg p-6">
      <div className="flex items-center gap-4">
        <SkeletonCircle size="xl" />
        <div className="flex flex-1 flex-col gap-3">
          <SkeletonText size="heading" lines={1} />
          <Skeleton shape="text" width="40%" />
        </div>
        <Skeleton shape="pill" width={96} />
      </div>
      <SkeletonRect height={140} className="mt-6" />
      <SkeletonText lines={2} size="sm" className="mt-5" />
    </SkeletonGroup>
  );
}
```

### Accessibility

- Shapes are aria-hidden. Wrap a loading region in SkeletonGroup, or give a preset its own label, so screen readers hear one polite "Loading…" instead of nothing.
- Remove the skeleton (and the status) as soon as content arrives so the real content is announced in its place.
- The live demos on this page pass role="none": a skeleton that is already on screen when the page loads should not be announced. Keep the status role for a skeleton that appears after a user action.
- One shared shimmer beam; it does not run under reduced motion.

### All exports on this page

- Skeleton — Skeleton: one placeholder shape that holds the layout while content loads.
- SkeletonCard — A content card preset: media, author row, text and actions, in a SkeletonGroup.
- SkeletonCircle — An avatar or icon placeholder: a Skeleton circle.
- SkeletonGroup — Wraps skeleton shapes: a named loading region (role="status" with a visually hidden label) and the box the shimmer sweeps across in one beam.
- SkeletonList — Rows of a list, inbox or table: avatar, two lines, a trailing pill, in a SkeletonGroup.
- SkeletonRect — A box: media, a chart, a thumbnail.
- SkeletonText — Lines of text.
- defaultSkeletonLabels — English defaults of SkeletonLabels.


### When to use Skeleton

- Use SkeletonCard as a skeleton loading state while a product or article card loads, so the 16:9 media block, avatar, text lines and button pills occupy the same space as the real card and nothing jumps.
- Use SkeletonList for an inbox, a user table or a settings list, where each row has an avatar, two text lines and a trailing pill, and rows count is set to match the page size.
- Compose your own layout from Skeleton shapes inside SkeletonGroup for a dashboard widget, so one beam of light crosses every shape in step and the region is named once.
- Skip it for tiny waits or actions that start from a click; Spinner suits a button or inline wait, and Empty state is the right component once loading has finished with no data.
- Pair it with GlassCard for the final content, Avatar for the loaded profile, and a persistent status region if you want a reliable spoken Loaded message.


### Frequently asked questions

#### How do I build a react skeleton loader that matches my layout?

Use the presets SkeletonCard and SkeletonList, or compose Skeleton with shape rect, text, pill or circle, plus SkeletonText, SkeletonCircle and SkeletonRect. Text skeletons use the same line box as the real text, 20px for 14px text, so the content does not shift when it arrives.

#### How do screen readers know something is loading?

Shapes are aria-hidden. Wrap a region in SkeletonGroup, or give a preset its own label, and it becomes a role="status" region that says Loading politely, once. Pass label={null} on a preset inside a group so it is not announced twice, and remove the skeleton when content arrives.

#### Does the shimmer run for users who prefer reduced motion?

No. The sweep of light is never drawn under reduced motion, so the shapes are simply still. Otherwise one band crosses a whole group in a single beam using transform only. Set shimmer={false} on a Skeleton, SkeletonText or a preset to turn the sweep off yourself.

#### How do I size the placeholders?

Skeleton takes width and height as numbers in px or as strings such as "60%"; a circle's height defaults to its width. SkeletonText takes lines, 3 by default, size from xs to heading, and lastLineWidth, 62% by default. Use className, such as h-4 or rounded-sheen-lg, for the rest.
