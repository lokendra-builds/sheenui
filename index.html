Glass has depth

Backdrop, rim light and content are separate layers. Scroll and they separate: each moves at its own speed, on transforms only.

  • Backdrop

    Blur and saturation of whatever sits behind: the layer that makes glass read as glass.

  • Rim light

    A specular edge that follows the pointer, lit from the top left on every surface.

  • Content

    Text and controls sit on top, always AA-legible, turning solid when transparency is reduced.

About SheenUI

The short version of what the library is, how it handles glass, motion and accessibility, and how to install it.

SheenUI is a library of glassmorphism React components: buttons, inputs, dialogs, menus, tables and more, drawn as frosted glass with a tint, a backdrop blur and a lit rim. Three glass levels come from a few Tailwind CSS v4 tokens, and every surface turns solid when someone asks for reduced transparency or more contrast, so text stays readable on any background. Taken together it is a glassmorphism UI kit for React rather than a single effect.

Browse all glass UI components, learn the system in glass design tokens, or see how contrast is checked in accessible glassmorphism.

Liquid Glass is the Apple look that bends the background behind a panel like a lens. SheenUI’s Liquid Glass React component does it with an SVG displacement map in Chrome and Edge, and falls back to ordinary frosted glass in Safari and Firefox, so every browser gets a good result.

The Liquid Glass CSS and React guide shows the code, and the best glassmorphism React libraries compares the alternatives honestly.

The animation comes from Motion (formerly Framer Motion). Buttons lift and press, switches spring, tabs slide a pill to the active tab, and a shared set of springs and durations keeps every component in the same rhythm. Reduced motion turns movement into short fades.

The animated React components page lists the effects, including a border beam, a macOS-style dock and a number ticker. Patterns for your own code are in 12 Framer Motion examples.

The chart set covers line, area, bar and donut charts, funnels, heatmaps, treemaps, Sankey diagrams and more, 48 chart components in all. Each has a glass tooltip you can drive with the arrow keys, a color-blind-safe palette and a table view of the same data.

Start with the animated React charts gallery, or open the React line chart, bar chart and donut chart pages. Accessible React charts explains the reading model.

Blocks are whole sections made only from SheenUI components. There are 20 of them, from a glassmorphism login form and an OTP verification page to a pricing table, a checkout form and an AI chat UI.

5 full glassmorphism dashboard templates cover web analytics, SaaS revenue, e-commerce, product analytics and crypto. Browse them all as React Tailwind blocks.

Every component is a registry item, so one command copies its source and installs the packages it needs:

npx shadcn@latest add https://lokendra-builds.github.io/sheenui/r/glass-card.json

SheenUI needs React 19.2+ and Tailwind CSS v4 (the Tailwind v4 glass UI setup shows the two CSS imports) and is free under the MIT license. The installation page and the guide to installing in Next.js and Vite list the tested steps.

Frequently asked questions

SheenUI is a free, open-source (MIT) library of glassmorphism and Liquid Glass React components. It has 86 components (67 UI components and 19 effects), 48 charts and 20 blocks, animated with Motion and built on Base UI and Tailwind CSS v4. You copy the source into your app and own the code, including for commercial projects.

Glassmorphism is a UI style where surfaces look like frosted glass: a translucent tint, a background blur (CSS backdrop-filter) and a thin, light border, over a colorful background. SheenUI ships three glass levels as Tailwind CSS v4 utilities; the glassmorphism React tutorial builds one from scratch.

Glassmorphism blurs what is behind a surface. Liquid Glass, Apple’s design language since iOS 26, also bends that background like a lens and adds a bright rim. SheenUI’s LiquidGlass component refracts in Chrome and Edge and shows frosted glass in Safari and Firefox. See Glassmorphism vs Liquid Glass.

The refraction uses an SVG displacement map inside backdrop-filter, which only Chromium browsers support today. Safari and Firefox get SheenUI's normal frosted glass instead, so nothing breaks.

It can be. SheenUI checks text contrast on the glass (WCAG AA, at least 4.5:1), turns the glass solid when the user asks for reduced transparency or more contrast, and switches to system colors in Windows forced-colors mode. Under reduced motion, movement becomes short fades. Read accessible glassmorphism for the details.

It uses Motion for React, the library formerly called Framer Motion: the motion package, imported from motion/react. The Framer Motion to Motion guide explains the rename.

Yes. SheenUI is MIT-licensed, so you can use, change and ship the copied source in personal and commercial projects. It is at version 0.1 and is not on npm yet: you install it with the shadcn CLI or by copying the files a page lists.

React 19.2 or newer, Tailwind CSS 4.1 or newer, Motion 14 and Base UI 1.9 or newer. There is no tailwind.config file: the glass tokens and utilities are plain CSS for Tailwind v4.

Both are copy-the-source libraries, so you own the code. shadcn/ui is a neutral, flat design system on Radix. SheenUI is glass by default (frosted and Liquid Glass surfaces, two style presets, light and dark), is built on Base UI, animates with Motion and adds charts, blocks and dashboards. You can install SheenUI items through the shadcn CLI and use both side by side.

Copy the folders listed in each page’s “Files to copy” box into a React 19.2+ and Tailwind CSS v4 app, or use the shadcn CLI with one registry URL per component. The installation page has the commands and the Next.js and Vite notes, and the Tailwind v4 glass UI setup covers the two CSS imports.
