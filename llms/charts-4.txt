## Lollipop Chart for React

URL: https://lokendra-builds.github.io/sheenui/charts/lollipop
Sidebar name: Lollipop chart

A React lollipop chart: a thin stem and a dot per value, so long ranked lists stay calm, with reference lines and highlights. Animated, accessible, MIT.

What it is: A React lollipop chart gives all the reading of a bar chart with a fraction of the ink: a thin stem and a dot per value. Pass data as readonly LollipopItem[]: takes one item per stem: { label, value }.

### Example 1 of 2: Ranked, with an average

Feature adoption across accounts. Change the order and every row slides to its new place; the dashed line marks the average. Hover, tap or arrow through the rows.

```tsx
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
import { LollipopChart } from "@/components/sheenui/charts/lollipop-chart";
import { type LollipopItem } from "@/components/sheenui/charts/lollipop-chart/model";
import { LollipopTable } from "@/components/sheenui/charts/lollipop-chart/table";
// Package build (after the first npm release, or a packed tarball): import { ChartCard, LollipopTable, LollipopChart, type LollipopItem } from "@sheenui/theme";

const adoption: LollipopItem[] = [
  { label: "Dashboards", value: 78 },
  { label: "Saved filters", value: 64 },
  { label: "Scheduled reports", value: 37 },
  { label: "Alerts", value: 52 },
  { label: "CSV export", value: 71 },
  { label: "API access", value: 23 },
];
const pct = (n: number) => Math.round(n) + "%";
const average = Math.round(adoption.reduce((sum, d) => sum + d.value, 0) / adoption.length);

export function Example() {
  return (
    <ChartCard
      title="Feature adoption"
      table={<LollipopTable data={adoption} sort="descending" reference={{ value: average, label: "Average" }} format={pct} caption="Feature adoption by share of accounts" />}
    >
      <LollipopChart
        data={adoption}
        sort="descending"
        reference={{ value: average, label: "Average" }}
        highlight={["Alerts", "Scheduled reports"]}
        format={pct}
        aria-label="Share of accounts using each feature"
      />
    </ChartCard>
  );
}
```

### Example 2 of 2: Upright, around a baseline

Month-on-month change in signups. Values below the baseline reach down, so growth and decline read at a glance; the sign is in every label, never only in the direction.

```tsx
import { LollipopChart } from "@/components/sheenui/charts/lollipop-chart";
import { type LollipopItem } from "@/components/sheenui/charts/lollipop-chart/model";
// Package build (after the first npm release, or a packed tarball): import { LollipopChart, type LollipopItem } from "@sheenui/theme";

const signupChange: LollipopItem[] = [
  { label: "Jan", value: 12 },
  { label: "Feb", value: 8 },
  { label: "Mar", value: -4 },
  { label: "Apr", value: 15 },
  { label: "May", value: 21 },
  { label: "Jun", value: -9 },
];
const signed = (n: number) => (n > 0 ? "+" : "") + n + "%";

export function Example() {
  return (
    <LollipopChart
      layout="vertical"
      data={signupChange}
      color={7}
      format={signed}
      valueLabel="Change in signups"
      aria-label="Month-on-month change in signups"
    />
  );
}
```

### Accessibility

- The chart is a focusable figure named by its aria-label (the chart title), with a one-line reading hint as its description and, inside a ChartCard with a table view, aria-details pointing at that table; moving through it announces each value politely, once. Each move announces the item, its value and its difference from the reference line.
- LollipopTable is the same data as a real table. Pass it to ChartCard's table prop and the Chart / Table tabs let anyone read every value without color or sight.
- Under reduced motion nothing morphs: the stems and dots render at their final values and new data replaces the old at once.

### All exports on this page

- LollipopChart — A lollipop chart: a thin stem from the baseline to a dot at each value.
- LollipopTable — Every item with its value (and its difference from the reference line), in the chart's order.
- defaultLollipopChartLabels — The built-in English strings of LollipopChart; spread it into your own labels and change what you need.


### When to use the lollipop chart

- Use it as a ranked chart when a bar chart would feel heavy, such as top customers by revenue or countries by NPS, since thin stems make small differences between long values visible.
- Use reference to draw an average or target line, and highlight to emphasize the items that matter while the rest step back to neutral gray.
- Set baseline when the stems should not start at zero; values below it reach the other way, which gives a diverging lollipop around a midpoint.
- Skip it when you have only two or three items, where a plain Bar chart is clearer, or when each item has a before and after value, where a Dumbbell chart shows the change.
- Pair it with ChartCard and LollipopTable for a text view, plus SegmentedControl to flip sort between descending and ascending, and Badge to label the reference value.


### Frequently asked questions

#### How do I make a lollipop chart in React?

Pass data as items with a label and a value, and an optional color, plus aria-label. A thin stem runs from the baseline to a dot, and showValues prints each value next to its head. valueLabel names the value axis.

#### Horizontal or vertical?

layout auto draws sideways rows, best for ranked lists and long names, and goes upright on wide charts with short names. You can force horizontal or vertical. Sideways charts grow with the number of rows, while height applies to upright ones.

#### Does sorting animate?

Yes. sort takes none, descending or ascending, and changing it slides each row to its new place, while new values glide. On first view stems grow from the baseline in a staggered sweep. Under reduced motion, drawing and re-sorting are instant.

#### How are items announced to assistive tech?

The chart is a figure named by its title, with the keyboard hint as its description and aria-details pointing at the table view in a ChartCard. Tab focuses it, arrow keys along the item axis move between items, Home and End jump to the ends, and Escape clears. Each move announces the item, its value and the difference from the reference line.

### When to use the marimekko chart

- Use it as a mosaic (mekko) chart for market maps, where each column is a customer segment sized by its revenue and the stacked cells show which product lines or competitors hold that segment.
- It works for a revenue-by-region and product breakdown in a board deck, because column width carries the region's size while cell height carries the product's share inside it.
- Try cellText value when readers want the numbers rather than percentages, for example fiscal revenue per product line printed inside each cell wherever it fits.
- Skip it when you have more than a handful of columns or need exact comparisons across categories; PercentBarChart or a plain BarChart reads more cleanly than narrow columns with clipped text.
- Pair it with ChartCard and its Chart / Table tabs, MarimekkoTable for a text version with totals and shares, and seriesLegend so each stacked part is named once, outside the cells.


### Frequently asked questions

#### What does a Marimekko chart show that a stacked bar does not?

Column width is proportional to each column's total, so you see segment size and composition in one picture. A 100% stacked bar gives every category the same width, which hides how large each segment actually is.

#### How do I make the cells print values instead of shares?

Set cellText to value; the default is share, and none turns labels off. Text appears only where it fits, column names and shares under the plot also print only where they fit, and every value stays available in the tooltip and the table.

#### Can cells be clickable for drill-down?

Yes, pass onCellClick. It fires on click, Enter or Space, and on touch devices on the second tap, with column, series, seriesLabel and value. The arrow keys move between cells and Home and End reach the bottom or top part of a column.

#### How many series can I stack in a column?

Up to eight, since colors come from fixed palette slots and negative values count as 0. Use the series array with key, label and optional color for each part, and the index prop to name the column key in every data row.

### Frequently asked questions

#### Do I need d3-force for a network graph in React?

No. The force layout (link springs, charge, gravity and collision) is written inside the component and computed in small chunks between frames. It gives the same layout on every load. You can tune it through the forces prop.

#### How are node sizes and link weights set?

A node's value sets its area, and a link's value sets its line weight. Repeated source and target pairs add up, links to unknown ids are left out, and nodes can carry a group that maps to a named palette slot through groups.

#### How do I navigate the graph with a keyboard?

Arrow keys move to the nearest node in that direction, Page Down and Page Up step through every node in order, and Home and End go to the first or last node. Plus and minus zoom, 0 fits the whole graph, Escape clears the reading, and Enter or Space calls onNodeClick.

#### Why are some node names missing?

With showLabels set to auto, the default, names print only where they fit without colliding, and more appear as you zoom in. Use all to print every name or none to hide them; the tooltip and NetworkTable still carry the full names.

### Frequently asked questions

#### What happens when my React pie chart has too many slices?

maxSlices defaults to 6 and accepts 2 to 6. Beyond that, the smallest slices fold into a neutral Other whose tooltip lists what is inside. PieTable keeps every original row and marks the ones drawn inside Other.

#### How do I set slice colors?

Each item can carry color, a fixed palette slot from 1 to 8; by default the slot follows position, never rank. No two drawn slices ever share a color, so a slice keeps its hue when the data reorders.

#### Is the pie chart accessible without a mouse?

It is a focusable figure named by its title, described by the keyboard hint, and one tab stop. Right or Down moves to the next slice, Left or Up to the previous one, Home and End jump to the ends, and Escape clears the reading. Each move announces slice, value and share.

#### Can I localize the labels and number formats?

Yes. format and formatPercent control values and shares, and labels overrides strings such as other, inOther, noData and the keyboard instructions. emptyState replaces the No data message shown when every value is 0.

### When to use the polar area chart

- Use it as a Nightingale rose (coxcomb) chart for cyclical categories such as months, hours of the day or compass points, where wedge position carries meaning and a circle makes the cycle obvious.
- It recreates Nightingale's rose: several series, such as causes of mortality per month, stack outward while each wedge's area stays proportional to its value.
- It suits a 24-hour traffic profile with one series and one hue, where wedge position and name identify the hour and labels thin out on narrow screens.
- Skip it when readers need to compare exact values across categories; a BarChart is easier to read, and RadarChart fits comparing profiles across several unrelated measures.
- Pair it with ChartCard for the title and Chart / Table tabs, PolarAreaTable for exact numbers, and polarAreaLegend when several series stack outward in the same wedge.


### Frequently asked questions

#### What is the difference between area and radius scaling?

The scale prop defaults to area, where the radius grows with the square root so wedge area stays true to the value. Choose radius when your data is a familiar 0 to 100 score; it makes large values look bigger than they are.

#### How many series can a polar area chart stack?

One or more; several stack outwards, each with a fixed color slot. Past eight, the first seven keep their slots and the rest fold into Other. Data rows are listed clockwise from 12 o'clock, with the index key naming each wedge such as the month.

#### How do I read wedges with the keyboard?

Focus the chart, then Right or Down moves to the next wedge clockwise, Left or Up to the previous one, and Home and End go to the first or last wedge. Escape stops reading. Hover and tap read a wedge too.

#### Why do some wedge names disappear on a phone?

Names never collide: with many wedges, like 24 hours, labels thin out on narrow screens instead of overlapping. Every wedge still has a tooltip and appears in PolarAreaTable, and reduced motion draws marks at final values.

### Frequently asked questions

#### How many rings can a radial bar chart have?

Two to five measures, outermost ring first. Each datum is label, value, an optional max and optional color. Items without their own max use the chart-level max, which defaults to 100, so a ring represents progress toward a goal.

#### What is the difference between arc and ring variants?

The default arc draws three-quarter arcs and prints each name and value in the open quarter. Variant ring closes the rings, marks the seam with a 2px gap and lists the measures beside them, so you do not need a separate legend.

#### Can the labels show values instead of percentages?

Yes. display defaults to percent, the share of the goal, and value prints the number. Use format and formatPercent to change either one. The labels prop overrides strings including the table headers.

#### How is it navigated with the keyboard?

The chart is one tab stop. Arrow keys move between measures, Home and End jump to the first or last one, and Escape clears the reading. Each move announces the measure, its value and its share, and hover reads a ring in the center.

### Frequently asked questions

#### How do I define the band around the line?

Each series object takes key, lower and upper, the data keys of its band's bounds, plus an optional bandLabel and color. The series prop is meant for one to three lines. The band uses the line's own hue at low opacity.

#### How do I mark where the forecast starts?

Pass forecastFrom with the x value where actuals end. From the last actual the line turns dashed and the region is tinted and tagged with a Forecast label. Strings such as that tag can be overridden through labels.

#### What happens when some data points are missing?

Leave the value out of the row. Gaps in the data stay gaps, so the line and band break there instead of dipping to zero. RangeAreaTable prints a dash for a missing value so the gap is also visible in text.

#### Should the y-axis start at zero?

By default no: zero is false because a band reads best when the axis hugs the data. Set zero to keep it on the axis. curve defaults to monotone, smooth lines that never overshoot a value, or linear for straight segments.

### All exports on this page

- RidgelineChart — Distributions stacked as overlapping ridges (a joyplot): how a measure is spread in each group.
- RidgelineTable — Each group's count, five-number summary and mean.
- defaultRidgelineChartLabels — The built-in English strings of RidgelineChart; spread it into your own labels and change what you need.


### When to use the ridgeline chart

- Use it as a joy plot to compare how a measure is distributed across groups, such as monthly delivery times where you want to see both the typical time and how much spread there is.
- It suits showing change in spread over time, for example orders getting faster and more predictable month by month apart from a December rush.
- Try fill sequential for salary bands by role, where a light to dark ramp along the value axis means position and color say the same thing.
- Skip it when you have only a few observations per group or need exact quartiles; BoxPlot states them directly, and Histogram shows one distribution in detail with real bin counts.
- Pair it with ChartCard and its Chart / Table tabs, RidgelineTable for the count, median, mean and range as text, and a segmented control to switch between shared and each scale.


### Frequently asked questions

#### What data does a ridgeline chart expect?

An array of groups, each with a label and raw values, top to bottom. The chart computes densities itself using a Gaussian kernel with Silverman's bandwidth per group, so you pass observations, not pre-binned counts.

#### How do I make ridges spikier or smoother?

Use bandwidth, in value units; smaller is spikier. By default each group gets Silverman's bandwidth. overlap controls how many rows a ridge rises into, default 2, and rowHeight sets row height in px, default 34.

#### What does the scale prop do?

With the default shared, one density scale is used so a tight group stands taller. Set each to give every ridge the same peak height, which helps compare shapes. showMedian draws a dashed tick at each median by default.

#### What can a reader get from each ridge?

Hovering, tapping or arrowing reads a ridge's median, mean, middle 50%, range and count. Down or Right moves to the next ridge, Up or Left to the previous, Home and End to the first and last, and Escape stops reading.

## Sankey Diagram for React: Flow Charts

URL: https://lokendra-builds.github.io/sheenui/charts/sankey-diagram
Sidebar name: Sankey diagram

A React Sankey diagram with no chart dependency: ribbons sized by flow for user journeys and revenue-to-profit, with a computed layout. Accessible.

What it is: A React Sankey diagram draws flows between stages as ribbons whose thickness is the amount, laid out without a chart library. Pass links as readonly SankeyLink[]: { source, target, value } objects, and optionally nodes with an id, a label and a color slot.

### When to use the sankey diagram

- Use it as a Sankey chart for an income statement, tracing revenue streams through costs to profit, with ribbon thickness showing how much of each stream ends up where.
- It fits a hiring pipeline or a signup funnel with drop-offs, where align left makes candidates who leave early stop early and linkColor source colors each ribbon by its source stage.
- It also works as a user flow chart for traffic, showing where visitors come from and which pages they go to, with hover tracing every path through a node.
- Skip it when flows are bidirectional or form cycles, since links that would close a cycle are left out; a ChordDiagram or NetworkGraph represents those, and FunnelChart suits a single linear sequence.
- Pair it with ChartCard for the title and Chart / Table tabs, SankeyTable as the text version, and onNodeClick or onLinkClick to filter a DataTable beside it.


### Frequently asked questions

#### What data shape does a Sankey diagram need?

A links array of source, target and value, plus an optional nodes array giving each node an id, a label and a color slot from 1 to 8. A node named only in a link takes its id as its label. Repeated pairs are summed, and zero, negative or self links are dropped.

#### Can I control how nodes line up in columns?

Yes, align takes justify, left, right or center. The default justify puts sinks in the last column. Left places nodes by distance from a source, right by distance to a sink. nodeWidth, nodePadding and linkColor refine the look.

#### How does a Sankey diagram behave on a phone?

minColumnWidth sets the narrowest gap between columns, default 96px. A narrower card scrolls the diagram sideways inside its own container instead of squeezing ribbons. Labels move inside the diagram on narrow cards and print only where they fit.

#### How do I explore a Sankey with the keyboard?

Up and Down move between nodes in a column, Right follows the first outgoing flow and Left the first incoming one. Home jumps to the first node and End to the last node of the final column. Enter or Space calls onNodeClick or onLinkClick for the active item.
