### Example 1 of 12: Line chart

Click a legend key to hide a series (the axis re-fits); hover one to dim the others. The dashed line is the previous period. Download it from the card's menu.

```tsx
import { ChartCard } from "@/components/sheenui/charts/chart-parts/chart-card";
import { ChartTable } from "@/components/sheenui/charts/chart-parts/empty-table";
import { seriesLegend } from "@/components/sheenui/charts/chart-parts/legend-tooltip";
import { formatCompact, type CompareSeries } from "@/components/sheenui/charts/chart-utils";
import { LineChart, PREVIOUS_SERIES_KEY } from "@/components/sheenui/charts/line-chart";
// Package build (after the first npm release, or a packed tarball): import { ChartCard, ChartTable, LineChart, PREVIOUS_SERIES_KEY, formatCompact, seriesLegend, type CompareSeries } from "@sheenui/theme";

const usd = (n: number) => "$" + formatCompact(n);

const data = [
  { month: "Jan", organic: 61000, organicPrev: 52000, paid: 34000, referral: 15000 },
  { month: "Feb", organic: 64500, organicPrev: 54500, paid: 36500, referral: 15800 },
  { month: "Mar", organic: 69000, organicPrev: 56000, paid: 38200, referral: 17100 },
  { month: "Apr", organic: 72800, organicPrev: 59500, paid: 41000, referral: 17600 },
  { month: "May", organic: 78100, organicPrev: 61000, paid: 43600, referral: 18900 },
  { month: "Jun", organic: 83400, organicPrev: 63800, paid: 45200, referral: 19700 },
];

// color is a palette slot (1–8); compareKey names the previous-period value in each row.
const series: CompareSeries[] = [
  { key: "organic", label: "Organic", color: 1, compareKey: "organicPrev" },
  { key: "paid", label: "Paid", color: 2 },
  { key: "referral", label: "Referral", color: 3 },
];

export function Example() {
  return (
    <ChartCard
      title="Monthly revenue by channel"
      legend={[
        ...seriesLegend(series, "line"),
        { label: "Previous period", color: "var(--sheen-fg-subtle)", kind: "line", dashed: true, key: PREVIOUS_SERIES_KEY },
      ]}
      exportable
      table={<ChartTable data={data} index="month" series={series} format={usd} />}
    >
      <LineChart data={data} index="month" series={series} format={usd} aria-label="Monthly revenue by channel" />
    </ChartCard>
  );
}
```

### Example 2 of 12: Area chart with a brush

A gradient wash that fades to transparent. The brush under a long series zooms it: drag the window, drag its edges, or use the arrow keys on them.


### Example 12 of 12: Live data

useLiveData appends a row on an interval into a sliding window and pauses off-screen, in hidden tabs and on Pause. With live, new points slide in from the right instead of morphing.

```tsx
import { Button } from "@/components/sheenui/button/button";
import { useLiveData, type ChartRow, type ChartSeries } from "@/components/sheenui/charts/chart-utils";
import { LineChart } from "@/components/sheenui/charts/line-chart";
// Package build (after the first npm release, or a packed tarball): import { Button, LineChart, useLiveData, type ChartRow, type ChartSeries } from "@sheenui/theme";
import { useRef } from "react";

const initial: ChartRow[] = [
  { t: "0s", v: 800 },
  { t: "2s", v: 830 },
];
const series: ChartSeries[] = [{ key: "v", label: "Requests" }];

export function RequestsPerSecond() {
  const ref = useRef<HTMLDivElement>(null);
  const { data, paused, setPaused } = useLiveData(initial, {
    next: (rows, tick) => ({ t: tick * 2 + "s", v: Math.round(Number(rows[rows.length - 1]?.v ?? 800) + (Math.random() - 0.5) * 140) }),
    interval: 1500,
    max: 16,
    ref, // pauses while this element is off-screen
  });

  return (
    <>
      <div ref={ref}>
        {/* data takes a mutable array: spread the hook's read-only window */}
        <LineChart live data={data} index="t" series={series} aria-label="Requests per second" />
      </div>
      <Button onClick={() => setPaused(!paused)}>{paused ? "Resume" : "Pause"}</Button>
    </>
  );
}
```

### Accessibility

- Every interactive chart is a focusable figure named by its title and described by the reading instructions (the same key on every chart, `labels.instructions`, a string or a function); inside a ChartCard with a table, `aria-details` points at the table view. The active values are announced once, politely.
- Every chart has a table view (Chart / Table tabs), so no value depends on color or on seeing the marks.
- Legend keys are toggle buttons (pressed = shown); hiding or showing a series is announced.
- Event markers are read out with the data point they sit on; status colors always come with a word or an icon.
- Reduced motion: charts appear at their final values, data changes jump, and live charts stop sliding.
- Windows High Contrast: legend keys gain outlines, the active tab and brush window use system colors.

### About charts

#### Overview

SheenUI's React charts are animated, accessible chart components for Tailwind CSS v4: smooth curves, gradient fills, draw-in entrances, previous-period comparison, clickable legends, annotations, a brush, synced crosshairs and PNG, SVG and CSV export. As a shadcn charts alternative, each chart has a table view of the same data.

Open any card above for its live demo, props and keyboard map, or start with the [line chart](https://lokendra-builds.github.io/sheenui/charts/line-chart), the [bar chart](https://lokendra-builds.github.io/sheenui/charts/bar-chart) and the [donut chart](https://lokendra-builds.github.io/sheenui/charts/donut-chart).

#### Frequently asked questions

#### What chart types does SheenUI include?

Line, area, bar, donut and sparkline charts, plus funnels, heatmaps, treemaps, sankey diagrams, candlesticks, maps and more, all drawn with the same glass tooltip, legend and table view.

#### Are the charts accessible?

Yes. Every chart can be read with the arrow keys, announces the point it is on, and has a table view of the same data. Status colors always come with a word or an icon, and reduced motion shows final values.

#### Can I use them with my own data?

Each chart takes plain arrays of objects. Pass the rows and the series, and the axes, legend, tooltip and table view are built from them.


### Line, area, bar and donut

The everyday charts, documented here. Smooth curves, gradient fills, draw-in and grow-from-baseline entrances, previous-period comparison, clickable legends, annotations, a brush, synced crosshairs and PNG / SVG / CSV export. As a shadcn charts alternative, each chart has a table view.

### Chart-wide features

The same building blocks power every chart above and the dashboards: synced crosshairs, annotations, export, live data and i18n.

### When to use a line chart

Use a React line chart when the question is how a number changes over time: revenue by month, requests per second, sign-ups per week. ### Frequently asked questions

#### How do I make a React line chart accessible?

Give it an aria-label and a table view. SheenUI's line chart is a focusable group: the arrow keys move a crosshair along the data, the values are announced, and the Table tab shows the same numbers.

#### Does it work with Tailwind CSS v4?

Yes. The chart reads its colors from the same design tokens as the rest of SheenUI, so it follows the light and dark theme and both style presets without extra classes.

#### Can I compare with the previous period?

Yes. Give a series a compareKey and the previous value is drawn as a dashed line, with its own legend key.

#### How many series can a line chart show?

Eight. The palette has eight slots and they are never cycled: a ninth series is drawn in neutral grey, so fold the smallest into an Other series instead. With more than three series, each line also gets its own dash rhythm and marker shape (patterns), so lines stay apart without color.

#### Does the value axis start at zero?

Yes by default. Set zero to false to fit the axis to the data, which suits rates, prices and temperatures that live far from zero. A truncated axis exaggerates change, so say so in the chart title.

#### Smooth or straight lines?

The default curve is monotone: smooth, and it never overshoots a real value, so a peak is never drawn higher than the data. Use curve="linear" when you want straight segments between readings, such as sparse measurements.

#### What does the Table tab contain?

A real table made with LineTable: one row per x value, one column per series, a caption, column headers and row headers. A previous-period series gets its own column, labelled with the series name and (previous).

#### Can it show live or streaming data?

Yes. Set live and pair it with useLiveData: when rows slide by, the lines slide left instead of morphing. Give people a pause control, because moving values are hard to read.

When you need several series, [the stacked area chart](https://lokendra-builds.github.io/sheenui/charts/stacked-area-chart) and [the range area chart](https://lokendra-builds.github.io/sheenui/charts/range-area-chart) keep them readable. ### How the fill behaves

The fill is drawn once per series from the line down to the baseline and fades with the gradient, so a lone series reads as a soft silhouette of its own total. Two overlapping series show through each other where the lower one is the smaller, but the upper fill hides the lower line where it is the larger, so keep to one or two series and let the legend toggle the rest off.

The line on top of the fill keeps the same crosshair and point markers as the line chart, so reading a month never depends on the shading. Because the fill grows from the baseline, a truncated value axis makes a small change look like a large block of colour: leave zero on unless the title says the axis is cut.


### Frequently asked questions

#### What is the difference between an area chart and a line chart?

An area chart fills the space under the line, which stresses volume and totals. Use it for one or two series; with many series the fills overlap and a line chart reads better.

#### Can the gradient fill be turned off?

Yes. Set gradient to false for a flat soft wash instead of the fade. The fill follows the series color from the theme either way.

#### How do I make a stacked area chart in React?

Use StackedAreaChart, which has its own page: each series stacks on the running total, and it can show percent shares. AreaChart is a LineChart with the fill turned on, so its series overlap rather than stack.

#### Does the area fill start at zero?

Yes by default: the value axis keeps zero and the fill runs to the baseline. Set zero to false to fit the axis to the data; the fill then runs to the bottom of the plot, which exaggerates change, so prefer a line chart for rates and prices.

#### How do I zoom into a long series?

Set brush. A range selector appears under the chart; drag its handles, or focus it and use the arrow keys, Page Up and Page Down, and Home and End.

#### How do I keep an area chart accessible?

The chart is one tab stop and the arrow keys read each point and announce every series value. The Chart / Table tabs give the same numbers as a real table, so no value depends on the gradient, which is decoration.

### When to use a bar chart

Use a React bar chart to compare values across categories: plans, countries, products or weeks. Bars start at zero, so their lengths compare honestly. Choose grouped bars to compare series side by side, stacked bars to show a total and its parts, and horizontal bars when the labels are long.

For a ranked list with inline values try [the bar list](https://lokendra-builds.github.io/sheenui/charts/bar-list); for positive and negative values, [the diverging bar chart](https://lokendra-builds.github.io/sheenui/charts/diverging-bar); for shares that always add up to 100 percent, [the 100% stacked bars](https://lokendra-builds.github.io/sheenui/charts/percent-stacked-bar-chart). A trend over time reads better in [a line chart](https://lokendra-builds.github.io/sheenui/charts/line-chart).


### Frequently asked questions

#### How do I make a stacked or horizontal bar chart in React?

Pass stacked for stacked bars and layout="horizontal" for horizontal ones; showValues prints the value at the tip of each bar.

#### Are the bars readable by screen readers?

Yes. The chart is a focusable group, the arrow keys read one category at a time, and the Table tab holds the same data.

#### Grouped, stacked or horizontal bars?

Grouped (the default) compares series within a category. Stacked compares totals, but only the bottom segment sits on a common baseline, so the upper ones are hard to compare. Horizontal (layout="horizontal") suits long category names and rankings.

#### Can bars show the previous period?

Yes. Give a series a compareKey and each bar gets a mark at the previous value. This works for unstacked bars; stacked bars do not draw it.

#### Does the value axis start at zero?

Yes. Bar length is the encoding, so the baseline stays at zero; a truncated bar axis misleads. For values far from zero use a line chart with zero set to false.

#### How are negative values drawn?

Below the baseline. The Table tab shows the signed number, so the direction never depends on the bar alone.

#### What does the Table tab contain?

A real table made with BarTable: one row per category, one column per series, a caption, column headers and row headers. With more than three series the bars also get hatch patterns, so the legend does not rely on color alone.

### When to use a donut chart

A React donut chart, which some teams call a doughnut chart, shows how one total divides into a few parts, such as traffic sources, plan mix or storage by file type. The hole in the middle holds the total, which a plain pie chart has no room for, and the ring stays legible on a glass card.

### Frequently asked questions

#### How many slices should a donut chart have?

At most six. Beyond that the slices are too thin to compare; group the small ones into an Other slice or switch to a bar chart.

#### What does the center show?

The total by default, and the label and value of the hovered or focused slice. Pass labels.center to name the total.

#### Donut chart or pie chart?

Use the donut when the total matters: the center carries it as text. Use the pie chart (its own page) when only the shares matter and you want the whole disc. Both take a list of labelled values.

#### How do screen readers read a donut chart?

Tab focuses the ring and the arrow keys step slice by slice, announcing the label, the value and its percentage of the total. The center total is text, not an image, and the Table tab (DonutTable) lists slice, value and share.

#### Can people hide slices?

Yes. Legend entries are toggle buttons (Enter or Space) and the percentages and center total update for the slices left. Control it with hiddenSlices and onHiddenSlicesChange, or start with defaultHiddenSlices.

#### How do slices stay apart without color?

With patterns: with more than three slices each slice after the first gets its own hatch (or set patterns yourself), and the legend and table name every slice, so the chart never depends on hue.

#### What data shape does it take?

An array of slices, each with a label and a value, plus an optional color and a key for legend toggling. Pass format and locale to change the number text. When there is nothing to plot, emptyState is shown instead of an empty ring.

### Accessibility

- The sparkline is an image with a name: write the direction into the aria-label ("Revenue trend, rising").
- It never carries information a sighted reader could not also get from the number beside it.
- Reduced motion: the line is drawn at once, without the draw-in.

### When to use a sparkline

Use a React sparkline when there is no room for a full chart but the direction of a number matters: KPI tiles, table rows, list items. It answers one question, is this going up or down, at a glance.

Keep sparklines honest: use the same time range for every tile in a row, label the period near the number ("last 7 days"), and do not mix a rising line with a bad number without saying so in the label. Because the line has no axis, a sparkline can exaggerate small changes; the arrow and percent change next to the headline number give the scale.

Skip it when readers need exact values or a time axis: a sparkline has none and exaggerates small changes, so use a [React line chart](https://lokendra-builds.github.io/sheenui/charts/line-chart). Skip it for a single data point, and for series with fewer than about five points, where the number alone is clearer. For counts per bucket use [the sparkbar](https://lokendra-builds.github.io/sheenui/charts/sparkbar), and for whole dashboards of tiles see [the web analytics dashboard](https://lokendra-builds.github.io/sheenui/dashboards/web-analytics).


### Frequently asked questions

#### What is a sparkline?

A sparkline is a tiny, axis-free line chart that shows the shape of a trend next to a number, in a stat tile or a table cell.

#### How does a sparkline stay accessible?

It is an image with a spoken summary: pass an aria-label such as "Revenue trend, rising", because the line itself has no values a screen reader could read.

#### What does the spoken summary say, and can I translate it?

With aria-label set, the name is that label plus a generated summary: "Weekly signups: 7 points, min 4, max 12, latest 12". Reword or translate it with labels.summary, and set locale for the number format. Without aria-label the sparkline is decorative and hidden from assistive tech.

#### Sparkline or Sparkbar?

A sparkline is one line over many points, for the direction of a trend. The sparkbar draws one bar per period, with the latest bar at full strength and history in a lighter tint, which suits counts per bucket.

#### How is the data shaped and sized?

Pass values as a number array, oldest first; non-numeric entries are skipped. The width follows the container and the height is 40 px unless you set height. area adds a soft fill under the line, curve="linear" swaps the default monotone curve for straight segments, and emptyState (default "No data") shows when there are no values.

### Accessibility

- Keyboard and screen-reader users get a single focusable figure labelled by the chart title, with a short reading hint as its description; inside a ChartCard with a table view, aria-details links it to the table. ### When to use the 100% stacked bar chart

- Use it as a percentage bar chart for a plan mix by region, where Free, Pro and Team customers are counted in very different volumes and you care about each region's proportions rather than its size.
- It suits time-spent breakdowns by team, such as building, meetings and support, where every row must be read as a share of 100% and long team names truncate inside a horizontal layout.

### Frequently asked questions

#### How do I build a 100% stacked bar chart in React with SheenUI?

Pass data rows, an index key such as region, and a series array with key, label and a fixed color slot from 1 to 8 to PercentBarChart, plus a required aria-label. Every row is scaled to 100%, and negative values count as 0.

#### What happens to a category whose values are all zero?

It gets an empty track instead of a misleading bar, so a new team with no data yet does not look like a full or broken bar. The page demo shows a row named New team with every value at 0, drawn as an empty track.

#### Which keys move between segments with the keyboard?

The chart is one tab stop. In the horizontal layout, Up and Down move between bars and Left and Right between segments; in the vertical layout the pairs swap. Home and End jump to the first or last bar, and Escape clears the readout.

#### Can I show the percentage inside each segment?

Set showValues. A share is printed only when it fits with room to spare, on a surface chip that keeps contrast on any segment color. Use formatPercent to change the format, and the tooltip still gives the raw value and the share.
